# ADR-0303: v3.7 Freeze & Release Pipeline

## Status

Accepted

## Context

Phase 55 完成后进入 v3.7 冻结。

## Decision

采用 v3.7 冻结：pom 3.7.0-SNAPSHOT、release.yml v3.7.0 +
Phase55BenchmarkTest/Baseline、`docs/release/v3.7.0-release-notes.md`、
全量回归 ≥14730。

## Alternatives

1. 不冻结：无法发布；
2. 只验证不回归：质量不可控。

## Consequences

优点：可发布、可回归。

缺点：Raft 边角/线性化仍为进程内验证。

风险：真实 Runner 复审仍需外部环境。

## Implementation

`pom.xml`、release.yml、release-notes.sh、
`src/test/java/io/tieringkv/ci/ReleaseV37Test.java`、
`docs/release/v3.7.0-release-notes.md`。
