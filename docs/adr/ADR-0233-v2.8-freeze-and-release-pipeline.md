# ADR-0233: v2.8 Freeze & Release Pipeline

## Status

Accepted

## Context

Phase 45 完成真实门禁收敛 v11、跨云一阶段、多表 JOIN / 窗口下推、
全球统一时钟、自治 PD 无人值守、TiKV 跨机基准与真实凭据 v3，需要
冻结 v2.8.0 并扩展发布流水线。

## Decision

- release.yml 增加 v2.8.0 / v2.8.0-rc* 标签；
- Benchmark 步骤接入 Phase45BenchmarkTest + Phase45ProductionBaselineTest；
- 旧客户端兼容矩阵（ADR-0103）继续执行；
- `docs/release/v2.8.0-release-notes.md` 记录能力/兼容性/已知限制。

## Alternatives

1. 跳过发布流水线：无法交付发布候选；
2. 覆盖旧标签：破坏冻结协议。

## Consequences

优点：v2.8.0 发布候选可追踪。

缺点：无。

风险：真实 Runner 门禁仍未闭环，发布候选以 JVM 级证据 + 精确登记为准。

## Implementation

`.github/workflows/release.yml`、
`src/test/java/io/tieringkv/ci/ReleaseV28Test.java`、
`docs/release/v2.8.0-release-notes.md`。
