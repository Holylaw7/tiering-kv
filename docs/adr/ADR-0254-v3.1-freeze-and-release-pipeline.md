# ADR-0254: v3.1 Freeze & Release Pipeline

## Status

Accepted

## Context

Phase 48 完成真实门禁收敛 v14、多组织联邦仲裁、RL 多智能体、量子/卫星
硬件适配、法规自动映射、TiKV 回归闭环与真实凭据 v6，需要冻结 v3.1.0
并扩展发布流水线。

## Decision

- release.yml 增加 v3.1.0 / v3.1.0-rc* 标签；
- Benchmark 步骤接入 Phase48BenchmarkTest + Phase48ProductionBaselineTest；
- 旧客户端兼容矩阵（ADR-0103）继续执行；
- `docs/release/v3.1.0-release-notes.md` 记录能力/兼容性/已知限制。

## Alternatives

1. 跳过发布流水线：无法交付发布候选；
2. 覆盖旧标签：破坏冻结协议。

## Consequences

优点：v3.1.0 发布候选可追踪。

缺点：无。

风险：真实 Runner 门禁仍未闭环，发布候选以 JVM 级证据 + 精确登记为准。

`.github/workflows/release.yml`、
`src/test/java/io/tieringkv/ci/ReleaseV31Test.java`、
`docs/release/v3.1.0-release-notes.md`。
