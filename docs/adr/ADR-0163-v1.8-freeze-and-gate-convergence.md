# ADR-0163: v1.8 Freeze & Gate Convergence

## Status

Accepted

## Context

v1.7 后全球自治/合规能力进入冻结窗口；跨地域基准、CI 容器 E2E、kind、
磁盘混沌等真实执行门禁仍待 Runner，需要收敛表精确登记。

## Decision

1. `release.yml` 扩展 v1.8.0 标签 + Phase35BenchmarkTest 接入；
2. 门禁收敛表：每项状态 / 阻塞原因 / 预期消除阶段；
3. 本环境可执行部分（JVM 级混沌/基准扩展）先行验证；
4. 未执行项如实登记，禁止伪报完成。

## Alternatives

1. 不冻结：接口漂移；
2. 跳过门禁：发布风险。

## Consequences

优点：v1.8 契约稳定、门禁透明可追踪。

缺点：跨地域执行依赖 CI/裸机。

风险：网络成本不可控，需超时与重试。

## Implementation

代码影响范围：`release.yml` + 基准测试 + 门禁收敛表 +
`docs/{deployment/gate-convergence,benchmark/phase35-production-report,release/v1.8.0-release-notes}.md`。
