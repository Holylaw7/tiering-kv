# ADR-0275: v3.3 Freeze & Release Pipeline

## Status

Accepted

## Context

Phase 51 完成命令族补齐后进入 v3.3 冻结：release.yml 接入 v3.3.0
标签与 Phase51 基准，旧客户端兼容矩阵继续执行。

## Decision

采用 v3.3 冻结：

- pom revision 升至 3.3.0-SNAPSHOT；
- release.yml 增加 v3.3.0-rc*/v3.3.0 标签 + Phase51BenchmarkTest /
  Phase51ProductionBaselineTest；
- `docs/release/v3.3.0-release-notes.md` + 版本一致性校验；
- 全量回归 ≥13190 全绿。

## Alternatives

1. 不冻结持续加命令：版本不可发布；
2. 只加命令不改流水线：发布无法回归；
3. 修改冻结协议：破坏兼容承诺。

## Consequences

优点：命令面可发布、兼容可回归、版本一致。

缺点：命令面仍非全量 Redis（hash/list/set/zset 待后续阶段）。

风险：新命令与既有网关/事务路径交互需持续验证。

## Implementation

`pom.xml`、`.github/workflows/release.yml`、`scripts/release-notes.sh`、
`src/test/java/io/tieringkv/ci/ReleaseV33Test.java`、
`docs/release/v3.3.0-release-notes.md`。
