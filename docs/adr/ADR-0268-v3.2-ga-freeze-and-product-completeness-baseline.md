# ADR-0268: v3.2 GA Freeze & Product Completeness Baseline

## Status

Accepted

## Context

Phase 50 完成工程基座与门禁终态后，v3.2.0 从 RC 进入 GA。需要一次
正式的完成度基线：能力分层（PRODUCT / EXPERIMENTAL / ADAPTER）、
技术债终态、成品判定清单。

## Decision

采用 v3.2 GA 冻结与完成度基线：

- `docs/release/v3.2.0-ga-release-notes.md` 定稿；
- `ProductCompletenessBaseline`：能力矩阵分层 + 技术债终态表 +
  成品判定清单；
- README / ROADMAP / CHANGELOG / AGENT_CONTEXT 同步；
- 全量回归 `mvn test` 0 failures（目标 ≥12660）；
- checkpoint-before/after + 合并 develop。

## Alternatives

1. 不冻结继续开发：无法形成可发布版本；
2. 全部能力宣称 PRODUCT：掩盖实验性现状；
3. 无基线报告：第三方无法独立评审完成度。

## Consequences

优点：发布可追溯、能力分层诚实、判定标准可执行。

缺点：实验能力被显式标注后，产品定位更保守。

风险：能力分层需要随迭代持续更新。

## Implementation

`io.tieringkv.operations.ProductCompletenessBaseline`、
`src/test/java/io/tieringkv/operations/ProductCompletenessBaselineTest.java`、
`docs/review/product-completeness-baseline.md`、
`docs/release/v3.2.0-ga-release-notes.md`。
