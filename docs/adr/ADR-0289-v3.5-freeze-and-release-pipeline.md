# ADR-0289: v3.5 Freeze & Release Pipeline

## Status

Accepted

## Context

Phase 53 完成接线/网络/事务后进入 v3.5 冻结。

## Decision

采用 v3.5 冻结：

- pom revision 3.5.0-SNAPSHOT；
- release.yml v3.5.0 标签 + Phase53BenchmarkTest/Baseline；
- `docs/release/v3.5.0-release-notes.md` + 版本一致性校验；
- 全量回归 ≥14140 全绿。

## Alternatives

1. 不冻结：无法发布；
2. 只接线不回归：质量不可控。

## Consequences

优点：可发布、可回归。

缺点：WATCH/EXEC 原子性限制需文档明确。

风险：连接级状态与既有测试交互需全量验证。

## Implementation

`pom.xml`、release.yml、release-notes.sh、
`src/test/java/io/tieringkv/ci/ReleaseV35Test.java`、
`docs/release/v3.5.0-release-notes.md`。
