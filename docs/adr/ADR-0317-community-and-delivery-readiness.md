# ADR-0317: Community & Delivery Readiness

## Status

Accepted

## Context

第三方参与需要贡献与安全流程。

## Decision

采用社区就绪：CONTRIBUTING 维护更新、issue 模板、
安全披露流程文档。

## Consequences

优点：参与路径清晰。

缺点：维护负担增加。

风险：披露流程需及时响应。

## Implementation

`CONTRIBUTING.md`、`docs/security/disclosure-policy.md` +
`src/test/java/io/tieringkv/operations/CommunityReadinessTest.java`。
