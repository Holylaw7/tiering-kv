# ADR-0226: v2.7 Freeze & Release Pipeline

## Status

Accepted

## Context

Phase 44 完成真实门禁收敛 v10、全局一阶段规模化、全算子下推、TSO
跨地域容灾、自治 PD 全自动、TiKV 对比基线与真实凭据 v2，需要冻结
v2.7.0 并扩展发布流水线。

## Decision

- release.yml 增加 v2.7.0 / v2.7.0-rc* 标签；
- Benchmark 步骤接入 Phase44BenchmarkTest + Phase44ProductionBaselineTest；
- 旧客户端兼容矩阵（ADR-0103）继续执行；
- `docs/release/v2.7.0-release-notes.md` 记录能力/兼容性/已知限制。

## Alternatives

1. 跳过发布流水线：无法交付发布候选；
2. 覆盖旧标签：破坏冻结协议。

## Consequences

优点：v2.7.0 发布候选可追踪。

缺点：无。

风险：真实 Runner 门禁仍未闭环，发布候选以 JVM 级证据 + 精确登记为准。

## Implementation

`.github/workflows/release.yml`、
`src/test/java/io/tieringkv/ci/ReleaseV27Test.java`、
`docs/release/v2.7.0-release-notes.md`。
