# ADR-0304: v3.7 GA Freeze & Release Execution

## Status

Accepted

## Context

Phase 55 完成 v3.7.0 RC 能力面，进入 GA 冻结与发布执行。

## Decision

采用 v3.7 GA 冻结：

- release.yml v3.7.0 标签 + Phase56BenchmarkTest/Baseline；
- `docs/release/v3.7.0-ga-release-notes.md` 定稿；
- 版本一致性校验全绿；无远程时发布就绪声明如实登记。

## Consequences

优点：可发布、可回归、无伪报。

缺点：真实发布触发待远程。

风险：与后续维护版本冲突需版本策略。

## Implementation

`release.yml`、`scripts/release-notes.sh`、
`src/test/java/io/tieringkv/ci/ReleaseV37GATest.java`。
