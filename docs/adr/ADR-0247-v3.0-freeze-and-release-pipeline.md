# ADR-0247: v3.0 Freeze & Release Pipeline

## Status

Accepted

## Context

Phase 47 完成真实门禁收敛 v13、全球统一仲裁、RL 下推、量子/卫星授时
原型、监管级审计、TiKV 回归告警与真实凭据 v5，需要冻结 v3.0.0 GA
并扩展发布流水线。

## Decision

- release.yml 增加 v3.0.0 / v3.0.0-rc* 标签；
- Benchmark 步骤接入 Phase47BenchmarkTest + Phase47ProductionBaselineTest；
- 旧客户端兼容矩阵（ADR-0103）继续执行；
- `docs/release/v3.0.0-release-notes.md` 记录能力/兼容性/已知限制。

## Alternatives

1. 跳过发布流水线：无法交付 GA 候选；
2. 覆盖旧标签：破坏冻结协议。

## Consequences

优点：v3.0.0 GA 候选可追踪。

缺点：无。

风险：真实 Runner 门禁仍未闭环，发布候选以 JVM 级证据 + 精确登记为准。

## Implementation

`.github/workflows/release.yml`、
`src/test/java/io/tieringkv/ci/ReleaseV30Test.java`、
`docs/release/v3.0.0-release-notes.md`。
