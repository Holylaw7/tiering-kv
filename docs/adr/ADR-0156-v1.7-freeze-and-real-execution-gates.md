# ADR-0156: v1.7 Freeze & Real Execution Gates

## Status

Accepted

## Context

v1.6 后商业化/自治能力进入冻结窗口；跨地域基准、CI 容器 E2E、kind、
磁盘混沌等真实执行门禁仍待 Runner。

## Decision

1. `release.yml` 扩展 v1.7.0 标签 + Phase34BenchmarkTest 接入；
2. Linux Runner 执行：TD-048/049、K8S-001、REL-001、BM-001/002、
   TD-051；本环境可执行部分先行验证；
3. 未执行项如实登记并给出精确阻塞原因，禁止伪报完成。

## Alternatives

1. 不冻结：接口漂移；
2. 跳过门禁：发布风险。

## Consequences

优点：v1.7 契约稳定、门禁透明。

缺点：跨地域执行依赖 CI/裸机。

风险：网络成本不可控，需超时与重试。

## Implementation

代码影响范围：`release.yml` + 基准测试 + 门禁文档 +
`docs/{deployment/real-runner-gates,benchmark/phase34-production-report,release/v1.7.0-release-notes}.md`。
