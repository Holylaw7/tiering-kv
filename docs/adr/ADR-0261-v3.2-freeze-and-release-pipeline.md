# ADR-0261: v3.2 Freeze & Release Pipeline

## Status

Accepted

## Context

Phase 49 完成 8 个 Goal 后进入 v3.2 冻结：release.yml 需接入 v3.2.0
标签与 Phase49BenchmarkTest，旧客户端兼容矩阵（ADR-0103）继续执行，
并发布 v3.2.0 release notes。

## Decision

采用 v3.2 冻结与发布流水线：

- release.yml 标签扩展 v3.2.0-rc*/v3.2.0，Benchmark job 接入
  Phase49BenchmarkTest / Phase49ProductionBaselineTest；
- 协议冻结继续：v1.0–v3.1 冻结协议不变，v3.2 扩展 additive；
- `docs/release/v3.2.0-release-notes.md` + `scripts/release-notes.sh`
  v3.2.0 分支。

## Alternatives

1. 不冻结持续开发：无法形成可交付版本；
2. 只加标签不加基准：发布质量无法回归；
3. 修改冻结协议：破坏兼容承诺。

## Consequences

优点：可发布、可回归、兼容承诺可审计。

缺点：v3.2 发布依赖全量回归与真实门禁记录。

风险：发布标签触发仍需 GitHub Runner 真实执行。

## Implementation

`.github/workflows/release.yml`、`scripts/release-notes.sh`、
`src/test/java/io/tieringkv/ci/ReleaseV32Test.java`、
`src/test/java/io/tieringkv/benchmark/Phase49BenchmarkTest.java`、
`docs/release/v3.2.0-release-notes.md`。
