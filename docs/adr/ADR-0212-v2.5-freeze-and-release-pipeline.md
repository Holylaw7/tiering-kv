# ADR-0212: v2.5 Freeze & Release Pipeline

## Status

Accepted

## Context

事务深度与执行收敛能力进入冻结窗口；v2.4 后需要冻结 v2.5 契约。

## Decision

1. `release.yml` 扩展 v2.5.0 标签 + Phase42BenchmarkTest 接入；
2. 旧客户端兼容矩阵（ADR-0103）继续执行；
3. 验收：v2.5.0 发布候选 + 兼容矩阵。

## Alternatives

1. 不冻结：接口漂移；
2. 跳过兼容矩阵：发布风险。

## Consequences

优点：v2.5 契约稳定。

缺点：需要回归门禁。

风险：门禁执行依赖 Runner。

## Implementation

代码影响范围：`release.yml` + 基准测试 +
`docs/{benchmark/phase42-production-report,release/v2.5.0-release-notes}.md`。
