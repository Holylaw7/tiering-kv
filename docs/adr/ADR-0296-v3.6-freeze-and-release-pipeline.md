# ADR-0296: v3.6 Freeze & Release Pipeline

## Status

Accepted

## Context

Phase 54 完成后进入 v3.6 冻结。

## Decision

采用 v3.6 冻结：pom 3.6.0-SNAPSHOT、release.yml v3.6.0 +
Phase54BenchmarkTest/Baseline、`docs/release/v3.6.0-release-notes.md`、
全量回归 ≥14470 次测试执行（Surefire 口径）。

## Alternatives

1. 不冻结：无法发布；
2. 只加功能不回归：质量不可控。

## Consequences

优点：可发布、可回归。

缺点：Stream/阻塞/通知仍为基础能力。

风险：事务回滚路径需全量验证。

## Implementation

`pom.xml`、release.yml、release-notes.sh、
`src/test/java/io/tieringkv/ci/ReleaseV36Test.java`、
`docs/release/v3.6.0-release-notes.md`。
