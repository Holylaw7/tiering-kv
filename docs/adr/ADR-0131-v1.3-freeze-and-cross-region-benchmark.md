# ADR-0131: v1.3 Freeze and Cross-Region Benchmark

## Status

Accepted

## Context

v1.2 后动态重分片、SQL 写事务、全球读水位进入冻结窗口，需要 v1.3
标签与跨地域真实基准。

## Decision

1. `release.yml` 扩展 v1.3.0 标签；
2. 跨地域基准（Linux Runner）：重分片迁移、SQL 写事务、全球读陈旧度、
   五中心 RTO/RPO（如实记录）；
3. `docs/benchmark/phase30-production-report.md` 输出；
4. 旧客户端兼容矩阵继续执行（ADR-0103）。

## Alternatives

1. 不冻结：接口漂移；
2. 仅本地基准：无法证明跨地域行为。

## Consequences

优点：v1.3 契约稳定、跨地域数据可发布。

缺点：跨地域执行依赖 CI/裸机。

风险：网络成本不可控，需超时与重试。

## Implementation

代码影响范围：`release.yml` + 基准测试 + 报告文档。
