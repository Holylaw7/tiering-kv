## 分析

- SQL 2PC 吞吐受决策日志落盘限制（每次提交 fsync 语义），
  属预期的持久化成本；
- 流量/选主/联邦为纯内存路径，达到内存级性能；
- 冷启动与跨地域网络成本未计入，不能直接外推生产容量。
