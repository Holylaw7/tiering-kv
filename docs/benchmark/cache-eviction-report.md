# 缓存淘汰基准报告（Cache Eviction Report）

Phase 3 · 2026-08-10

环境：本机 Windows，JDK 21（编译目标 17），单线程直连策略 API（不含网络 /
存储读写），JVM `-Xmx1g`。

## LFU 热度跟踪（100K 键，1M 次访问：50 万 GET + 50 万 PUT）

| 指标 | avg | P99 |
| --- | --- | --- |
| 查找（GET 事件） | 3.15μs | 7.40μs |
| 更新（PUT 事件） | 3.83μs | 8.80μs |

数据加载（100K 键）：367ms；条目数 100,000；内存开销估算 ≈ 9MB（96B/条目，
含索引，估算值）。

## 淘汰决策延迟（Eviction decision latency）

| 数据集 | avg | P99 |
| --- | --- | --- |
| 100K 条目 | 0.33μs | 0.90μs |
| 1M 条目 | 0.08μs | 0.30μs |

目标：淘汰决策 < 1ms ✅（余量 >1000×）。

说明：

- 本指标仅覆盖**候选选择**（TreeSet 首元素 O(1)），不含迁移与 IO；
  Phase 6 接入磁盘后，"完整淘汰延迟"需另行测量；
