# 内存引擎基准报告（Memory Engine Report）

Phase 2 · 2026-08-10

环境：本机 Windows，JDK 21（编译目标 17），MemTable（64 段 SkipList + 分段锁），
JVM `-Xmx1g`。

> ⚠️ 基准口径：本报告所有 GET 指标均为**存储层（Storage-layer）**——直连
> StorageEngine / MemTable API，不含 TCP / RESP / Command 开销；
> 不得将其表述为客户端端到端 GET 延迟。

## 存储层 GET 延迟（直连 Storage API，随机键，50,000 样本）

| 数据集 | P50 (ms) | P95 (ms) | P99 (ms) | 吞吐 (ops/s) |
| --- | --- | --- | --- | --- |
| 10K | 0.0006 | 0.0011 | 0.0015 | 591,312 |
| 100K | 0.0007 | 0.0015 | 0.0020 | 920,127 |
| 1M | 0.0009 | 0.0018 | 0.0026 | 791,689 |

存储层目标：P99 < 0.5ms ✅（1M 数据集 P99 ≈ 2.5μs，余量 >100×）。

| 线程数 | 吞吐 (ops/s) | 失败数 | 最终 size |

目标：100 线程读写稳定 ✅（0 失败，size 精确）。

## 端到端对比（Network end-to-end）

| --- | --- |
