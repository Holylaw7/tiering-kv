# Tiering-KV v5.0.2 Release Notes

- 发布日期：2026-10-24
- 类型：维护版本（版本号对齐 + 脚本去硬编码）

## 变更

### 版本号统一

| 位置 | 变更前 | 变更后 |
| --- | --- | --- |
| `pom.xml` 的 `revision` | 4.1.0 | **5.0.2** |
| `console-server/pom.xml` `version` | 1.0.0 | **5.0.2** |
| `ServerVersion.SOURCE_VERSION` | 4.1.0 | **5.0.2** |
| `VersionConsistencyTest` 断言 | 4.1.0 | **5.0.2** |

### 构建脚本去硬编码

- `scripts/dev-up.ps1`：内核构件与控制面构件改为按修改时间从
  `target` 目录挑选，不再写死 `4.1.0` / `1.0.0`；
- `scripts/version-check.sh`：发布说明路径改为按当前版本动态拼接
  （`docs/release/v<version>-release-notes.md`）。

## 制品

## 验证

- 内核全量回归：`mvn -o -B '-Dsurefire.excludedGroups=benchmark' test`

- 容器：`cd deploy/console && docker compose up -d --build`
