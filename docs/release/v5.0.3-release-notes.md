# Tiering-KV v5.0.3 Release Notes

- 发布日期：2026-10-24
- 类型：工程链路（发布自动化 + 发布门禁补强）
- 对应决策：ADR-0360

## 变更

### 1. 任意 `v*` 标签自动发版

`release.yml` 的标签触发此前是**逐版本硬编码**（最远只到 `v4.1.0`），
导致 v5.0.0 / v5.0.1 / v5.0.2 三次发布都只能手工执行。现改为：

```yaml
on:
  push:
    tags: ["v*"]
```

`checkpoint-*`、`phase-*` 等历史标签不匹配，不会误触发。

### 2. 发布门禁增加"前后端"作业

`release` 作业现在依赖三块：

| 作业 | 内容 |
| --- | --- |
| `test-shards` | 内核 3 分片全量测试 |
| **`console`（新增）** | 控制面 `mvn test`（45 用例）+ 前端 `npm ci && npm run build` |
| `release` | Benchmark → Trivy → GHCR 镜像 → Release |

这样"内核绿但前后端破"的新版本不会再被放行。

### 3. 发布说明生成器支持 v5/v6

`scripts/release-notes.sh` 新增分支：优先读取
`docs/release/v<version>-release-notes.md`，缺失时从 `CHANGELOG.md`
对应版本段落抽取，仍缺失则输出最小占位。新增版本无需再改脚本。
