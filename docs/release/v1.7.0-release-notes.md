# Tiering-KV v1.7.0 Release Notes

## 新能力

- 控制台 SaaS 产品化：仪表盘/市场/订阅视图 + RBAC API（ADR-0150）；
- AI 自治闭环：容量护栏控制器 + 流量限幅/熔断/回滚（ADR-0151）；
- 跨云数据网格联邦 + 数据主权（ADR-0152）；
- 法规合规自动化：法规映射 + 审计导出 + 合规报告（ADR-0153）；
- 企业级可观测性：跨 RPC 追踪 + 成本归因（ADR-0154）；
- 商业化运营指标：MRR / 试用转化 / 流失告警（ADR-0155）；
- v1.7 发布流水线与 JVM 级生产门禁（ADR-0156）。

## 兼容性

- v1.0–v1.6 冻结协议不变，新能力全部 additive；
- 不修改 Raft safety / MVCC consistency / 事务状态机。

## 测试

- Phase 34 新增 356 项（surefire 口径）；
- 全量回归 **4926/4926 全绿**（+6 容器门控跳过）。

## 已知限制

- 跨地域真实基准、CI 容器 E2E、kind、磁盘混沌待 Linux Runner；
- 控制台 UI 为快照渲染，无实时推送；
- AI 自治为策略护栏内执行。
