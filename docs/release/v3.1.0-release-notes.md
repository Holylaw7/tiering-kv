# Tiering-KV v3.1.0 Release Notes

## 定位

Enterprise-ready Distributed Database v3.1.0：Redis 协议兼容、LSM 冷热
分层、Multi-Raft 分布式事务、真实 Runner 门禁全量闭环与多组织联邦
一致性。

## 本版本能力

- 真实执行门禁收敛 v14 + 发布记录归档（ADR-0248）；
- 多组织联邦仲裁（ADR-0249）：组织边界 + 组织级仲裁 + 回退 2PC；
- RL 多智能体下推（ADR-0250）：加权 Q 聚合 + 反馈闭环，语义层一致；
- TSO 量子/卫星硬件适配（ADR-0251）：硬件接口 + 模拟 + 故障降级；
- 监管法规自动映射 + 证据链（ADR-0252）；
- TiKV 跨机回归闭环（ADR-0253）：自动重跑 + 趋势告警；
- 真实凭据网络验证 v6（ADR-0253）：可达性 + 认证 + 权限 + 配额 +
  延迟（TD-076 剩余项）；
- 发布流水线扩展 v3.1.0 标签 + Phase48BenchmarkTest / Baseline 接入。

## 兼容性

- v1.0–v3.0 冻结协议不变，v3.1 扩展 additive；
- 多组织联邦仅在组织仲裁通过时启用，否则回退 2PC；
- 多智能体只改决策层，语义层与上层 SQL 结果一致；
- 硬件适配单调不回拨；法规映射证据链可验证。

## 质量摘要

- 新增测试 ≥560；全量回归 ≥11625 全绿；
- 基准：见 docs/benchmark/phase48-production-report.md；
- 门禁收敛表：docs/deployment/gate-convergence-v14.md。

## 已知限制

- 真实 Linux Runner / 跨机 / 跨地域门禁待 Phase 49 执行；
- 联邦为组织级仲裁，跨监管域后续阶段；
- 多智能体为加权 Q 聚合，联邦学习后续阶段；
- 硬件适配为模拟，真实设备驱动待接入；
- 真实 S3/Spot 网络握手待 Runner。
