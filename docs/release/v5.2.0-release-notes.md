# Tiering-KV v5.2.0 Release Notes

- 发布日期：2026-11-25
- 类型：控制面生产加固、RESP 批量 Pipeline 与 TLS、前端性能重构与全链路质量门禁升级（O1–O5）
- 容器镜像（GHCR）：
  - `ghcr.io/holylaw7/tiering-kv:v5.2.0`（数据面内核）
  - `ghcr.io/holylaw7/tiering-kv-console-server:v5.2.0`（控制面后端）
  - `ghcr.io/holylaw7/tiering-kv-console-web:v5.2.0`（控制面前端）

## 核心变更

### 1. 权限收口与异步备份恢复（O1）
- `GET /api/v1/backups/{id}/download` 收紧至 `ADMIN + OPS` 角色（`VIEWER` 返回 `403`），前端同步隐藏无权限操作按钮。
- `POST /api/v1/backups/{id}/restore` 全面异步化至 `backupExecutor` 线程池，新增 Flyway `V7__backup_progress_tracking.sql`（`processed_keys`）与按 500 键 / 1 秒节流落库进度，前端提供实时进度条与页面重入自动续轮询。

### 2. RESP 批量 Pipeline 与数据面 TLS（O2）
- `RespClient` / `RespGateway` 新增 `executeBatch` 批量管线与 `TlsOptions`（TLS/SNI 及自定义 CA PEM 证书校验），新增 Flyway `V8__instance_tls_support.sql` 与实例表单 TLS 动态配置。
- `KeyspaceService` 与 `BackupService` 接入 100 键批量 Pipeline，大幅降低大库扫描与逻辑备份恢复往返开销：
  - 10,000 键全库 Gzip JSONL 导出：`0.76s`（产物 54,811 B）
  - 异步恢复 HTTP 提交：`30.57ms`，后台全量恢复完成：`0.607s`
  - `/keys/scan`（`COUNT=50`，100 轮采样 @ 10,000 键）：P50 `16.9ms` / P95 `40.43ms`

### 3. 生产安全收敛、告警 Webhook 通知与容器健康检查（O3）
- Actuator `/actuator/info`、`/actuator/metrics/**`、`/actuator/prometheus` 收紧至 `ADMIN` 角色；`ProductionConfigGuard` 新增静态加密主密钥校验及严格阻断开关 `console.security.require-encryption-in-prod`。
- 新增 `LoginAttemptStore` 与 `ClientIpResolver`，支持用户名 + IP 双维度登录限流及受信代理 CIDR 解析。
- 新增 Flyway `V9__alert_webhook_channels.sql` 与 `AlertWebhookDispatcher`（HMAC-SHA256 签名、静默窗口、3s 超时与 5xx 重试），前端告警中心新增“通知渠道”增删改与测试发送页签。
- `deploy/console/docker-compose.yml` 补全 `tiering-kv`（`:9100/healthz`）与 `console-server`（`/actuator/health`）健康检查；新增 `docker-compose.prod.yml` 与 `.env.example`。

### 4. Web 前端按需瘦身与组件重构（O4）
- 接入 `unplugin-auto-import` + `unplugin-vue-components` 按需解析 Element Plus，彻底消除 1,174.72 kB 全量 `element` 单体块，入口 CSS 从 `372.86 kB` 降至 `62.23 kB`（-83.3%），`chunkSizeWarningLimit` 收紧至 `600 kB` 且零告警。
- 新增防重入轮询 Composable `usePolling.ts`（后台标签页自动暂停、切回立即刷新）与 `ResizeObserver` 防抖重绘封装。
- 将 1,383 行的 `DashboardView.vue` 模块化拆分为 191 行主容器 + 4 个高内聚子组件（`InstanceSummaryStrip` / `TieringMemoryPanel` / `TrendChartsGrid` / `SstableInventoryDrawer`）。

### 5. CI 质量门禁统一与 E2E 扩容（O5）
- `console-server` 纳入 SpotBugs High（0 缺陷）与 JaCoCo 行覆盖率 ≥ 75% 门禁（实测 76.67%），同步接入 `test.yml` 与 `release.yml`。
- 前端单测扩容至 6 文件 29 项 Vitest；Playwright 全栈容器 E2E 扩容至 5 组 6 项全绿；清理 27 个未引用的历史临时调试探针脚本。
