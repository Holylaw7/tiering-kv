# Tiering-KV v3.6.0 Release Notes

## 定位

Enterprise-ready Distributed Database v3.6.0（RC）：Redis 协议兼容、
LSM 冷热分层、Multi-Raft 分布式事务、事务加固 / Stream / 生产验证。

## 本版本能力

- WATCH 版本守卫（ADR-0290）
- EXEC 原子性与回滚（ADR-0291）
- Stream 数据类型（ADR-0292）
- 阻塞命令（ADR-0293）
- 过期事件通知（ADR-0294）
- SQL/向量生产化（ADR-0295）

## 质量摘要

- 命令注册表 109 个；新增测试 ≥600；全量回归
  ≥14470 次测试执行全绿（Surefire 口径）
- 基准：docs/benchmark/phase54-production-report.md

## 兼容性

- v1.0–v3.5 冻结协议不变；v3.6 扩展 additive（STREAM 标签 5）。

## 已知限制

- EXEC 跨段顺序执行（回滚保证一致）；Stream 无消费组；
- BLPOP 等待占用 worker 线程；SQL/向量仍为实验分层。
