# Tiering-KV v3.7.0 Release Notes

## 定位

Enterprise-ready Distributed Database v3.7.0（RC）：分布式正确性验证、
Stream 消费组、事务日志持久化、文档产品化。

- 线性一致性验证（ADR-0297）
- Raft 边角验证矩阵（ADR-0298）
- 升级/备份演练（ADR-0299）
- Stream 消费组（ADR-0300）
- 跨段事务日志持久化（ADR-0301）
- 文档产品化（ADR-0302）

  ≥14730 次测试执行全绿（Surefire 口径）
