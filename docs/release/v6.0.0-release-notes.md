# Tiering-KV v6.0.0 Release Notes

- 发布日期：2026-11-26
- 类型：大版本底座现代化与零 CVE 例外清零（Spring Boot 4.2 / Spring Framework 7 / Jackson 3 / 关闭 `TD-085` / 前端 `npm audit` 0 漏洞）
- 容器镜像（GHCR，4 套全量发布）：
  - `ghcr.io/holylaw7/tiering-kv:v6.0.0`（数据面内核）
  - `ghcr.io/holylaw7/tiering-kv-operator:v6.0.0`（Kubernetes Operator 控制器）
  - `ghcr.io/holylaw7/tiering-kv-console-server:v6.0.0`（控制面后端，Spring Boot 4.2 / Jackson 3）
  - `ghcr.io/holylaw7/tiering-kv-console-web:v6.0.0`（控制面前端，Vue 3 / ECharts 6）

## 核心变更

### 1. 控制面底座全面升级至 Spring Boot 4.2 + Jackson 3（B1）
- **核心栈升级**：`console-server` 升级至 `spring-boot-starter-parent:4.2.0`，底层同步演进至 Spring Framework `7.1.0`、Spring Security `7.2.0`、Tomcat `11.0.27`、Hibernate `7.4.15.Final`、Flyway `12.11.0`、Logback `1.6.6`、Jackson `3.1.8` 与 `springdoc-openapi-starter-webmvc-ui:3.2.1`。接入 Boot 4 模块化 starter（`spring-boot-starter-flyway`、`spring-boot-starter-webmvc-test`、`spring-boot-starter-security-test`），移除全部历史 Spring Boot 3.5 临时 CVE 覆盖属性。
- **纯粹 Jackson 3 迁移（0 个 Jackson 2 `jackson-databind` 残留）**：
  - `JacksonConfig` 迁移至 `JsonMapperBuilderCustomizer` + `tools.jackson.databind.*` + `DateTimeFeature.WRITE_DATES_AS_TIMESTAMPS`，严格保持 `yyyy-MM-dd HH:mm:ss` 与 `non_null` JSON 输出格式；
  - `JwtService` 升级至 `jjwt:0.13.0` 并基于 Jackson 3 `JsonMapper` 自实现 `Serializer`/`Deserializer`，彻底移除 `jjwt-jackson` 传递依赖；
  - `SecurityConfig`、`AlertWebhookDispatcher`、`BackupService` 与 20 个测试类全面迁移至 `tools.jackson.databind.*` 及 `org.springframework.boot.webmvc.test.autoconfigure.AutoConfigureMockMvc`，新增 `Jackson3AndJwtCompatTest` 回归护栏。
- **外部契约 100% 向后兼容**：`/api/v1/**` REST 响应字段、日期格式、JWT 令牌结构与 MySQL Flyway V1–V10 迁移脚本保持零破坏性变更，`OpenApiSnapshotTest` 与前端 `openapi-typescript` 校验 **`0` 漂移**。

### 2. 零 Trivy 例外清零（关闭 `TD-085`）与前端全零漏洞升级（B2）
- **`.trivyignore` 正式归零**：彻底移除原登记于 `spring-webmvc 6.2.19` 的两条 CRITICAL 例外（`CVE-2026-47884`、`CVE-2026-47890`），有效忽略条目数归 **`0`**，技术债 `TD-085` 正式关闭。
- **常驻安全门禁**：`.github/workflows/test.yml` 新增 `security-scan` 作业，每次提交均先断言 `.trivyignore` 含 `0` 条有效规则，再打包全模块 JAR 并执行 Trivy `CRITICAL,HIGH` 严格扫描（`exit-code: 1`）；`console-and-web` 同步加入 `npm audit --audit-level=high` 校验。
- **`console-web` 零漏洞依赖现代化**：升级 `echarts@^6.1.0`、`vue-tsc@^3.3.14`、`mermaid@^12.3.0`、`typescript@~5.9.3`（并适配 `AlertsView.vue` `channelForm` ref），实现 **`npm audit` 全级别 `0 vulnerabilities`**（`critical=0 / high=0 / moderate=0 / low=0`），Vite 构建 0 超限告警（`echarts` 块 `537.62 kB < 600 kB`、首包 CSS `62.23 kB`）。

### 3. CI 洁净度与 Operator 清单同步（B3）
- 移除 `operator-kind-e2e` 未使用的宿主机 `setup-java` 缓存消除 `Path Validation Error` 警告，全部工作流达到 `attempt=1` 零注解通过；
- `deploy/operator/deployment.yaml` 与 `deploy/operator/kind-cluster-sample.yaml` 同步指向 `:v6.0.0` 官方镜像，`scripts/kind-operator-e2e.sh` 镜像替换逻辑升级为版本无关正则。

## 升级说明

- **数据面内核与存储格式**：本版本未变更 WAL / SSTable / Raft / 2PC / RESP 协议格式，数据面可平滑滚动升级。
- **控制面与数据库**：需 Java 21（镜像内置 Eclipse Temurin 21 JRE），MySQL 8 表结构与 `v5.3.0`/`v5.4.0`（Flyway V10）完全兼容，直接滚动替换 `tiering-kv-console-server:v6.0.0` 与 `tiering-kv-console-web:v6.0.0` 镜像即可。
