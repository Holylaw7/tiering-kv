# Tiering-KV v2.6.0 Release Notes

## 定位

Enterprise-ready Distributed Database v2.6.0：Redis 协议兼容、LSM 冷热
分层、Multi-Raft 分布式事务、全球规模调度与生产基线收敛。

## 本版本能力

- 跨区一阶段提交（ADR-0214）：主副本资格判定 + 失败回退 2PC（TD-079
  关闭方向）；
- Coprocessor 多算子联合下推（ADR-0215）：FILTER → PROJECT → AGGREGATE
  链（TD-080 关闭方向）；
- TSO 集群化（ADR-0216）：批量分配 + 单调推进 + 恢复不回退；
- 自治 PD 与全球自治联动（ADR-0217）：拓扑变化 → 计划 → 护栏执行 + 回滚；
- 生产级 Benchmark 基线（ADR-0218）：A/B/C 三级 + TiKV 对比口径；
- 真实凭据验证（ADR-0218）：S3/Spot 探测 + 降级登记（TD-076 关闭方向）；
- 真实执行门禁收敛 v9（ADR-0213）：可执行项全绿 + 未执行项精确登记；
- 发布流水线扩展 v2.6.0 标签 + Phase43BenchmarkTest / Baseline 接入。

## 兼容性

- v1.0–v2.5 冻结协议不变，新增路径 additive；
- 跨区一阶段仅在主副本全部合格时启用，否则回退 2PC；
- 多算子下推与上层 SQL 结果一致。

## 质量摘要

- 新增测试 ≥510；全量回归 ≥8867 全绿；
- 基准：见 docs/benchmark/phase43-production-report.md；
- 门禁收敛表：docs/deployment/gate-convergence-v9.md。

## 已知限制
