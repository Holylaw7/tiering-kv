- 类型：控制面 S3 真实对象存储闭环（M2）、无状态多副本高可用与实时故障转移门禁（M3）、内核扩展 INFO 段落全景可观测（M4）

  - `ghcr.io/holylaw7/tiering-kv:v5.3.0`（数据面内核）

  - `ghcr.io/holylaw7/tiering-kv-console-web:v5.3.0`（控制面前端）

## 核心变更

### 1. S3 / RustFS 真实对象存储加固与 CI 门禁（M2）
- `S3BackupStorageBackend` 增加有界超时保护（默认连接 5s / 读写 30s / 单次 API 60s，可通过 `console.backup.s3.*-timeout-ms` 调优）、统一 `IOException` 包装、错误日志凭据脱敏、`NoSuchBucketException` 精准识别与短暂故障后的重试安全。
- 新增端到端规范 `console-web/e2e/backups-s3-storage.spec.ts`：覆盖 `s3://tiering-backups` 自动建桶、204 键 5 类数据结构写入、UI 异步备份导出、流式 `.jsonl.gz` 下载解压校验、清库后 UI 异步恢复与精确值核对、留存清理与删除后 `404` 验证。
- `.github/workflows/test.yml` 新增 `docker-compose-s3-e2e` 真实容器门禁作业。

### 2. 控制面多副本无状态化与双副本高可用（M3，零新外部中间件）
- 新增增量迁移 `V10__multi_replica_coordination.sql`，纯复用既有 MySQL 8 创建 `console_lease` 与 `login_attempt` 两张轻量协调表，不引入额外外部缓存或协调中间件。
- 新增 `DbLeaseLockService`（`PROPAGATION_REQUIRES_NEW` 条件更新 + 主键冲突回退 + 同副本原地续租 + 宕机到期自动接管），消除控制面全部 3 类单机进程内状态：
  - `BackupService`：`export()` / `restore()` 临界区增加 `backup-op:instance:{id}` 跨副本互斥锁，并发提交严格返回 `200 / 409`；
  - `MonitorService` / `BackupRetentionService` / `RetentionService`：定时采集与清理任务通过租约选主防重（采集采用 2× 间隔租约防抖续租）；
  - `DbLoginAttemptStore`：实现多副本共享的用户名 + IP 双维度登录限流（`console.security.login-attempt-store=db`，生产与 HA Compose 默认启用），同步加固 `BootstrapDataInitializer` 并发冷启动幂等容错。
- 新增双副本 HA 部署覆盖 `deploy/console/docker-compose.ha.yml` 与 `deploy/console/nginx-ha.conf`，并在 CI 新增实时故障转移门禁 `docker-compose-ha-smoke`（实测双副本健康启动、跨副本共享 429 限流、单主采样 0 重复及主容器停机后 Nginx 无中断与租约自动切主）。

### 3. 内核扩展 INFO 段落全景可观测（M4）
- `SystemInfoView` 向后兼容新增 `sections` 字段，`SystemInfoService` 透出 `INFO` 全部非空段落（`Tiering` / `Persistence` / `Cluster` / `Replication` / `Txn` / `MVCC` / `Vector` / `MultiModel` / `Backup` / `Tracing` 及标准段），并对 `sections` 与 `config` 中口令/密钥/令牌类敏感字段统一脱敏为 `******`（保留 `total_keys` / `tiering_hot_keys` / `keyspace_hits` 等指标原值）。
- 同步更新 `docs/api/openapi.json` 与 `console-web/src/api/schema.d.ts`（0 漂移）。
- `SystemView.vue` 新增「内核扩展段落（INFO Sections）」分栏浏览面板：按扩展段优先排序、支持「仅扩展段落」筛选、实时关键词过滤、命中计数徽标与单段一键复制 KV 文本 / JSON，兼容标准 Redis 实例。
