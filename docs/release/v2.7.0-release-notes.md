# Tiering-KV v2.7.0 Release Notes

## 定位

Enterprise-ready Distributed Database v2.7.0：Redis 协议兼容、LSM 冷热
分层、Multi-Raft 分布式事务、真实执行门禁闭环与全球规模最终化。

## 本版本能力

- 真实执行门禁收敛 v10（ADR-0220）：可执行项全绿 + 未执行项精确登记；
- 全局一阶段提交规模化（ADR-0221）：3 地/5 地 + 回退 2PC +
  resolved-ts 联动（TD-079 规模化）；
- Coprocessor 全算子联合下推（ADR-0222）：JOIN/GROUP_BY/ORDER_BY/
  LIMIT（TD-080 规模化）；
- TSO 跨地域容灾（ADR-0223）：主备切换 + 恢复不回退；
- 自治 PD 全自动（ADR-0224）：风险分级 + 自动执行 + 人工熔断；
- 生产级 Benchmark 对比 TiKV 口径（ADR-0225）：A/B/C/D 四级；
- 真实凭据验证 v2（ADR-0225）：真实 HTTP 探针（TD-076 关闭方向）；
- 发布流水线扩展 v2.7.0 标签 + Phase44BenchmarkTest / Baseline 接入。

## 兼容性

- v1.0–v2.6 冻结协议不变，新增路径 additive；
- 全局一阶段仅在主副本全部合格时启用，否则回退 2PC；
- 全算子下推与上层 SQL 结果一致；
- TSO 容灾切换后时间戳单调不回退。

## 质量摘要

- 新增测试 ≥520；全量回归 ≥9412 全绿；
- 基准：见 docs/benchmark/phase44-production-report.md；
- 门禁收敛表：docs/deployment/gate-convergence-v10.md。

## 已知限制

- 真实 Linux Runner / 跨机 / 跨地域门禁待 Phase 45 执行；
- JOIN 仅等值内连接；TSO 容灾为主备模型；
- D 级基线为进程内多副本模拟，不等同跨机网络；
- 真实 S3/Spot 网络凭据验证待 Runner。
