# Tiering-KV v1.1.0 Release Notes

2026-08-11 · Phase 28 · Multi-Master & Advanced Query Engines

## 本版本新增

- 双向复制与 CRDT（ADR-0114）：VersionVector 环回抑制、LWW/GCounter/
  GSet/OrSet；
- 两地三中心容灾（ADR-0115）：DrTopology + 切换计划 + 演练 RTO/RPO；
- SQL 引擎（ADR-0116）：Hash Join、COUNT/SUM/AVG、GROUP BY、
  ExplainPlan；
- HNSW + 混合检索（ADR-0117）：层级索引 + 标量过滤 + 召回对比；
- SaaS 多租户（ADR-0118）：注册/审计/配额/集群生成；
- RPC 帧级令牌（ADR-0119）：信封 v1 兼容旧帧 + 权限授权。

## 质量

- 全量 **3216/3216 PASS**（+6 容器门控本地跳过）；
- 新增 251 项测试；单向复制与既有路径零回退；
- 基准见 docs/benchmark/phase28-production-report.md。

## 已知限制

- 跨地域 RTT/RTO/RPO 待 CI/裸机执行；
- HNSW 为原型级；SQL JOIN/聚合为内存执行；
- SaaS 网络/存储隔离待 K8s 配合。

## 升级路径

1. 备份 + PITR 检查点；
2. 滚动升级（quorum ≥2）；
3. `recover()` 补完决策；旧客户端兼容矩阵验证（ADR-0103）。
