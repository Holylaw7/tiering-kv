# Tiering-KV v1.0.0 Release Notes（GA 候选）

2026-08-11 · Phase 26 · v1 Release Freeze & Enterprise Readiness

## 定位

Redis 协议兼容、LSM 冷热分层、Multi-Raft 分布式事务 KV。

## 本版本新增

- v1.0 协议冻结（ADR-0103）：RESP2 / RPC v1 / 存储格式 v1 +
  ProtocolCompatibilityTest（51 项）；
- PITR 时间点恢复（ADR-0104）：WALArchive / Checkpoint / RestoreTimeline；
- CDC 流式变更（ADR-0105）：exactly-once checkpoint；
- Enterprise Security（ADR-0106）：RBAC 角色/权限 + 令牌生命周期；
- Kubernetes Operator（ADR-0107）：CRD + Planner/Controller；
- tierctl CLI + v1 发布流水线（release.yml）。

- 事务元数据 Multi-Raft 网络化（ADR-0099）：TxnMetadataNode 接入
  MultiRaftEndpoint 共享传输 + FileRaftLog/RaftPersistentState/Snapshot
  落盘，Coordinator → Netty RPC → 三节点元数据组，TD-050 关闭；
- CI 容器混沌管道（ADR-0100）：四 job（JVM E2E / container-e2e 故障注入 /
  kind-e2e / block-device-chaos）；
- 真实块设备混沌脚本与门控测试（ADR-0101）；
- Kubernetes 集群内验证脚本（ADR-0102）；
- 异步 RPC 响应支持（Raft 提案不阻塞 Netty 事件循环）。

## 质量

- 全量 **2701/2701 PASS**（+6 容器门控测试本地跳过）；
- 元数据 failover 110–118ms；快照/日志恢复 ≈250ms（不含端口等待）；
- 元数据提案 657–1077 ops/s（单写者）、1393 ops/s（8 写者），
  含 SYNC 日志 + 三节点复制（如实标注进程内 TCP 口径）。

## 已知限制

- TD-048/049 与 K8s 集群内验证的真实 Runner 执行待 GitHub Actions 触发；
- 元数据跨机基准（真实网卡 RTT）待裸机/CI；
- 网关 CLUSTER NODES/ASK（TD-038）与 AUTH/ACL 为下一版本方向。

## 升级路径

1. 备份元数据快照与 MVCC 索引；
2. 滚动升级逐节点替换（quorum ≥2）；
3. 升级后 `recover()` 补完决策；
4. `/readiness` 确认 leader 就绪后放流量。
