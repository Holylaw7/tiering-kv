# Tiering-KV v1.5.0 Release Notes

2026-08-11 · Phase 32 · Production Wiring & Global Validation

## 本版本新增

- SQL 写 2PC 生产接线（ADR-0138）：SqlTxn2PcExecutor 生命周期 + RBAC；
- 控制台 REST 服务（ADR-0139）：/tenants /metrics /alerts + 令牌鉴权；
- 并发自动重分片（ADR-0140）：多线程迁移 + 限速 + 安全合并；
- 网关冲突审计（ADR-0141）：亲和路由 + ConflictAuditLog；
- 全局多活自动选主（ADR-0143）：健康切换 + 多数防脑裂；
- 数据主权合规（ADR-0143）：驻留策略 + 违规拒绝。

## 质量

- 全量 **4251/4251 PASS**（+6 容器门控本地跳过）；
- 新增 251 项测试；复制/查询/重分片/多活路径零回退；
- 基准见 docs/benchmark/phase32-production-report.md。

## 已知限制

- 跨地域 RTT/冲突率/收敛时间待 CI/裸机；
- 控制台 TLS/限流由部署层提供；UI 待 Phase 33；
- 选主为健康探测模型（与 Raft term 联动待 Phase 33）。

## 升级路径

1. 备份 + PITR 检查点；2. 滚动升级（quorum ≥2）；
3. `recover()` 补完；4. 兼容矩阵验证（ADR-0103）。
