# Tiering-KV v2.4.0 Release Notes

## 新能力

- 真实执行门禁收敛表 v7 + JVM 级门禁扩展（ADR-0199）；
- 真实 S3 API 接入：put/get/delete + 模拟 fallback（ADR-0200，
  TD-073 关闭方向）；
- Spot 市场真实数据源：真实/模拟切换 + fallback（ADR-0201，
  TD-074 关闭方向）；
- 签名密钥轮换：双密钥原子切换 + 宽限期 + 回滚（ADR-0202，
  TD-068 关闭）；
- 物化视图对象存储生命周期联动：TTL → 过期规则 + 恢复保护
  （ADR-0203）；
- 生产级 LSM 演进：leveled compaction 计划 + Immutable MemTable
  轮转（ADR-0204）；
- PD 等价调度：放置约束 + 均衡计划 + 配额限流（ADR-0205）；
- v2.4.0 发布流水线。

## 兼容性

- v1.0–v2.3 冻结协议不变，新能力全部 additive；
- 不修改 Raft safety / MVCC consistency / 事务状态机。
