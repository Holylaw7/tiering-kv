# Tiering-KV v3.2.0 Release Notes

## 定位

Enterprise-ready Distributed Database v3.2.0（RC）：Redis 协议兼容、
LSM 冷热分层、Multi-Raft 分布式事务、真实 Runner 闭环归档与跨监管域
联邦一致性。

## 本版本能力

- 真实执行门禁收敛 v15 + 闭环归档（ADR-0255）
- 跨监管域联邦仲裁：域边界发现 + 域级仲裁 + 回退 2PC（ADR-0256）
- RL 多智能体联邦学习：FedAvg + 噪声注入 + 梯度裁剪（ADR-0257）
- 商用量子/卫星授时设备接入：设备 SPI + 主备切换（ADR-0258）
- 监管法规库 + 差异报告：版本化 + 摘要校验 + 轮换（ADR-0259）
- TiKV 回归归档 + 真实凭据 v7（ADR-0260，TD-076 剩余项）
- v3.2 冻结与发布流水线（ADR-0261）

## 质量摘要

- 新增测试 ≥570；全量回归 ≥12205/12205 全绿
- 基准：docs/benchmark/phase49-production-report.md（LOCAL 口径）
- 门禁收敛表：docs/deployment/gate-convergence-v15.md

- v3.2 扩展 additive，旧客户端兼容矩阵继续执行（ADR-0103）。
