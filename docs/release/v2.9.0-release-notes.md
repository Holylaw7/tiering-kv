# Tiering-KV v2.9.0 Release Notes

## 定位

Enterprise-ready Distributed Database v2.9.0：Redis 协议兼容、LSM 冷热
分层、Multi-Raft 分布式事务、真实 Runner 门禁闭环与全球一致性最终化。

## 本版本能力

- 真实执行门禁收敛 v12（ADR-0234）：可执行项全绿 + 未执行项精确登记；
- 跨云一阶段规模化（ADR-0235）：云 × 区混合拓扑 + 分层仲裁 + 回退 2PC；
- 窗口函数全族 / 动态下推（ADR-0236）：LAG/LEAD/SUM/COUNT/AVG OVER +
  运行时成本感知；
- TSO 跨云授时仲裁 + 防时钟回拨（ADR-0237）：多数云共识 + 回拨窗口告警；
- 自治无人值守全自动合规证明（ADR-0238）：审计链 + SHA-256 签名 +
  外部审计接口；
- TiKV 跨机基准定期回归（ADR-0239）：快照 + 趋势 + 告警；
- 真实凭据网络验证 v4（ADR-0239）：可达性 + 认证 + 权限（TD-076 剩余项）；
- 发布流水线扩展 v2.9.0 标签 + Phase46BenchmarkTest / Baseline 接入。

## 兼容性

- v1.0–v2.8 冻结协议不变，新增路径 additive；
- 跨云一阶段仅在分层仲裁通过时启用，否则回退 2PC；
- 窗口全族与上层 SQL 结果一致；
- 跨云授时单调不回拨，回拨超窗冻结并告警。

## 质量摘要

- 新增测试 ≥540；全量回归 ≥10491 全绿；
- 基准：见 docs/benchmark/phase46-production-report.md；
- 门禁收敛表：docs/deployment/gate-convergence-v12.md。

## 已知限制

- 真实 Linux Runner / 跨机 / 跨地域门禁待 Phase 47 执行；
- 动态下推为 EWMA 决策，强化学习在线决策后续阶段；
- 跨云仲裁为进程内多源模拟；合规签名为摘要（非监管级证书）；
- 真实 S3/Spot 网络握手待 Runner。
