# Tiering-KV v1.8.0 Release Notes

## 新能力

- 全球多活受限自治：容量/流量/重分片联动 + 策略围栏（ADR-0157）；
- 跨云实时物化视图：预聚合 + 刷新 + stale 标记（ADR-0158）；
- 合规即代码：法规版本化 + 持续审计流水线（ADR-0159）；
- Workload 感知成本优化：缩容/冷层/压缩建议 + 收益/风险（ADR-0160）；
- 多租户网络隔离：VPC 域 + 默认拒绝 + 白名单（ADR-0161）；
- SLA/SLO 管理：滚动窗口达成率 + 违约告警（ADR-0162）；
- v1.8 发布流水线与 JVM 级生产门禁（ADR-0163）。

## 兼容性

- v1.0–v1.7 冻结协议不变，新能力全部 additive；
- 不修改 Raft safety / MVCC consistency / 事务状态机。

## 测试

- Phase 35 新增 360 项（surefire 口径）；
- 全量回归 **5286/5286 全绿**（+6 容器门控跳过）。

## 已知限制

- 跨地域真实门禁、CI 容器 E2E、kind、磁盘混沌待 Linux Runner；
- 全球自治为策略围栏内执行；
- 物化视图为周期刷新，无 CDC 增量刷新。
