# Tiering-KV v1.4.0 Release Notes

2026-08-11 · Phase 31 · Autonomous Resharding & Global Active-Active

## 本版本新增

- 负载驱动自动重分片（ADR-0132）：阈值触发 + 冷却 + 熔断；
- SQL 写 2PC 端到端（ADR-0133）：WriteOp → Mutation → 2PC 提交；
- 向量双写迁移（ADR-0134）：窗口双写 + 原子切换 + 回滚；
- 全球 Active-Active（ADR-0135）：多地域写 + 环回抑制 + 冲突合并；
- 账单周期滚动（ADR-0136）：BillingScheduler 自动结算；
- 多云部署与迁移（ADR-0136）：参数化 + CloudMigration；
- 企业控制台（ADR-0137）：ConsoleApi（REST 原型 + RBAC）。

## 质量

- 全量 **4000/4000 PASS**（+6 容器门控本地跳过）；
- 新增 258 项测试；复制/查询/重分片路径零回退；
- 基准见 docs/benchmark/phase31-production-report.md。

## 已知限制

- 全球多活跨地域 RTT/冲突率/收敛时间待 CI/裸机；
- SQL 2PC 桥接需接真实分布式 2PC（Phase 32）；
- 控制台 REST 传输层/UI 待 Phase 32。

## 升级路径

1. 备份 + PITR 检查点；2. 滚动升级（quorum ≥2）；
3. `recover()` 补完；4. 兼容矩阵验证（ADR-0103）。
