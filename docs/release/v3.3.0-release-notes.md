# Tiering-KV v3.3.0 Release Notes

## 定位

Enterprise-ready Distributed Database v3.3.0（RC）：Redis 协议兼容、
LSM 冷热分层、Multi-Raft 分布式事务、Redis 命令族补齐。

## 本版本能力

- 字符串命令族（ADR-0269）：原子 + WAL 接入
- TTL 命令族（ADR-0270）：语义与 Redis 对齐
- 多键命令族（ADR-0271）：MGET/MSET/MSETNX/DEL/EXISTS
- 管理命令族（ADR-0272）：DBSIZE/FLUSHDB/SCAN/TYPE/CONFIG/CLIENT/
  COMMAND
- RESP2 兼容矩阵（ADR-0273）
- 网关命令路由与 CROSSSLOT（ADR-0274）

## 质量摘要

- 新增测试 ≥520；全量回归 ≥13190/13190 全绿
- 基准：docs/benchmark/phase51-production-report.md
- 命令延迟：docs/benchmark/command-latency-report.md

## 兼容性

- v1.0–v3.2 冻结协议不变；v3.3 扩展 additive（ADR-0103）；
- 命令错误文本与 Redis 7.x 对齐（差异见兼容矩阵文档）。

## 已知限制

- hash/list/set/zset、RESP3、Pub/Sub 待 Phase 52+；
- CLIENT 无会话态；跨段 MSET 原子性依赖网关同槽约束。
