- 发布日期：2026-11-27

  - `ghcr.io/holylaw7/tiering-kv-console-server:v6.4.0`（控制面后端）

- 发布资产：`checksums.sha256` + `tiering-kv-sbom.cdx.json`（CycloneDX 1.5 标准 SBOM）

## 核心变更

### 1. 备份完整性校验、Dry-Run 冲突预览与预恢复安全快照（D1）
- **Flyway V12 增量迁移（`V12__backup_integrity_and_audit_trace.sql`）**：为 `backup_record` 新增 `sha256`、`verify_status`（`UNVERIFIED`/`VERIFIED`/`CORRUPTED`）、`verified_at`、`pre_restore_backup_id`，并为 `op_log` 新增 `request_id` 及索引 `idx_op_log_request_id`。
- **导出期零额外 I/O 流式 SHA-256 摘要**：`BackupService` 在 Local 与 S3 双后端导出写入最终归档字节流时外包 `DigestOutputStream(SHA-256)`，实时落库精确哈希并将新建归档标记为 `VERIFIED`。
- **归档完整性校验（`POST /api/v1/backups/{id}/verify`，`ADMIN`/`OPS`）**：流式重算全文件 SHA-256 并同步执行 Gzip 解压与逐行 JSONL 校验，精准检出单字节静默损坏或对象篡改并标记 `CORRUPTED`、独立事务写入审计日志。
- **恢复前 Dry-Run 冲突预检与安全保护快照**：新增只读预览端点 `POST /api/v1/backups/{id}/restore/preview`（100 键批量 RESP Pipeline `EXISTS` 统计冲突覆写键、预计新增键、已过期跳过键、类型分布与冲突键样例）；扩展 `POST /api/v1/backups/{id}/restore` 支持可选 `createSafetySnapshot=true`，在回放前先在目标实例原子生成 `pre-restore-*` 保护快照并写入 `pre_restore_backup_id`，前端 `BackupsView.vue` 升级为两步「安全恢复向导」。

### 2. 键空间大键/前缀/TTL 诊断 + Prometheus 业务指标 + 全链路 Request-ID（D2）
- **键空间诊断分析器（`POST /api/v1/keys/analyze`，只读零阻塞）**：新增 `KeyspaceAnalyzerService`，基于有界游标 `SCAN` 与 100 键批量 RESP Pipeline 采集 `TYPE`/`TTL` 及按类型尺寸探针（`STRLEN`/`HLEN`/`LLEN`/`SCARD`/`ZCARD`/`XLEN`/`JSON.GET`），输出类型分布、TTL 健康度分桶、Top 业务命名空间前缀聚合、Top-N BigKeys 榜单与规则引擎优化建议；前端 `KeyspaceView.vue` 新增「大键 / 前缀 / TTL 诊断」页签（复用既有 ECharts 6 `BarChart`，点击大键直达详情抽屉）。
- **Micrometer / Prometheus 自定义业务指标体系（零新增外部依赖）**：新增 `ConsoleMetricsBinder` 与 `RespPoolHealthIndicator`，向 `/actuator/prometheus` 实时暴露被纳管实例指标（`tieringkv_instance_{up,memory_used_bytes,memory_ratio,ops_per_sec,keys_total,cold_tables,p99_latency_ms}`，实例删除时自动注销防高基数泄漏）、RESP 连接池治理指标（`tieringkv_console_pool_{active,idle,max,borrow_timeouts_total}`）及运维健康度指标（`tieringkv_console_{backups,restores,audit_events}_total`、`tieringkv_console_alerts_firing`）；开启 Spring Boot 4 标准 `/actuator/health/liveness` 与 `/actuator/health/readiness` 分离探针。
- **W3C `traceparent` / `X-Request-Id` 全链路关联**：新增最高优先级 `RequestCorrelationFilter`，自动透传 `X-Request-Id` 或提取 W3C `traceparent` 的 `trace-id`，串联 SLF4J 日志 MDC `[%X{requestId:-}]`、HTTP 响应头 `X-Request-Id`（CORS 已放行）与 `op_log.request_id`；`AuditController` 与 `AuditView.vue` 支持按 `Request ID` 精确检索、一键复制与 CSV 导出。

### 3. 标准 Helm v3 Chart、Grafana/Prometheus 观测包与 CycloneDX 1.5 SBOM（D3）
- **标准 Helm v3 全栈 Chart（`deploy/helm/tiering-kv/`）**：覆盖 `standalone`/`cluster` 双模式数据面（JDK 21 分代 ZGC + PVC）、多副本 HA 控制面（`replicaCount >= 2` 自动切换 `CONSOLE_LOGIN_ATTEMPT_STORE=db` 并渲染 `PodDisruptionBudget`、内置 `liveness`/`readiness` 探针）、动态 Nginx 反代前端与可选 Ingress、可选 Operator RBAC/Lease 及 Prometheus Operator `ServiceMonitor`/`PrometheusRule`；同步刷新 `deploy/kubernetes/tiering-kv/` 镜像标签至 `:v6.4.0`。
- **开箱即用观测包（`deploy/observability/`）**：提供直连 D2 指标的 10 面板 `grafana-dashboard.json`、10 条 `prometheus-alerts.yaml`（覆盖实例离线、热层 85%/95% 水位、P99 延迟、RESP 连接池超时/耗尽、备份/恢复失败及归档损坏）与接入指南。
- **零依赖 CycloneDX 1.5 SBOM**：升级 `scripts/sbom.sh` 支持 `--cdx` 标准 CycloneDX 1.5 JSON 输出（零新增 Maven/npm 插件风险，向后兼容纯文本模式）；CI 新增 `helm-and-observability-lint` 常驻门禁，发布流水线自动随 Release 上传 `tiering-kv-sbom.cdx.json`。

### 4. 第 9 组全栈 E2E 与 HA 观测指标门禁（D4）
- 新增第 9 组 Playwright 全栈 E2E 规范 `console-web/e2e/integrity-and-analyzer.spec.ts`，在真实 Docker Compose 全栈下验收备份 SHA-256 校验、Dry-Run 冲突预览与预恢复保护快照恢复、键空间 BigKey/前缀/TTL 诊断联动与审计 `Request ID` 检索闭环；
- 扩充 `docker-compose-ha-smoke` 门禁，验证双副本 `/actuator/health/liveness` 与 `/actuator/health/readiness` 返回 `UP`、双副本及主采集节点 `/actuator/prometheus` 真实暴露自定义 `tieringkv_*` 指标，以及经过 Nginx 反向代理后的 `X-Request-Id` 透传回写。
