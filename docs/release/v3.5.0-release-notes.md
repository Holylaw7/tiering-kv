# Tiering-KV v3.5.0 Release Notes

## 定位

Enterprise-ready Distributed Database v3.5.0（RC）：Redis 协议兼容、
LSM 冷热分层、Multi-Raft 分布式事务、RESP3 接线 / PubSub 网络 /
事务队列。

## 本版本能力

- RESP3 连接级接线（ADR-0283）
- Pub/Sub 连接级投递（ADR-0284）
- 集群广播 RPC（ADR-0285）
- 高级数据结构命令（ADR-0286）
- MULTI/EXEC 事务队列（ADR-0287）
- 连接生命周期清理（ADR-0288）

## 质量摘要

- 命令注册表 101 个；新增测试 ≥560；全量回归 ≥14140/14140 全绿
- 基准：docs/benchmark/phase53-production-report.md

## 兼容性

- v1.0–v3.4 冻结协议不变；v3.5 扩展 additive（RPC PUBSUB 帧 32/33）；
- RESP2 连接零影响（RESP3 需 HELLO 3）。

## 已知限制

- EXEC 非整体原子；LMOVE 双键顺序执行；WATCH 无版本守卫；
- HSCAN 单页快照；Pub/Sub 至少一次不落盘。
