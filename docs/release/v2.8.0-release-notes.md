# Tiering-KV v2.8.0 Release Notes

## 定位

Enterprise-ready Distributed Database v2.8.0：Redis 协议兼容、LSM 冷热
分层、Multi-Raft 分布式事务、真实 Runner 闭环 v11 与多云全球一致性。

## 本版本能力

- 真实执行门禁收敛 v11（ADR-0227）：可执行项全绿 + 未执行项精确登记；
- 跨云全局一阶段（ADR-0228）：多数云仲裁 + 回退 2PC + resolved-ts；
- 多表 JOIN / 窗口函数下推（ADR-0229）：N 表等值连接 +
  ROW_NUMBER/RANK + 下推成本模型；
- TSO 全球统一时钟（ADR-0230）：GPS/原子钟/NTP 混合授时 + 校准 +
  单调 + 恢复不回退；
- 自治 PD 无人值守（ADR-0231）：风险自校准 + 合规证明自动化 + 熔断；
- TiKV 跨机对比基线（ADR-0232）：跨机口径 + 本地进程内补充；
- 真实凭据网络验证 v3（ADR-0232）：认证握手探测（TD-076 剩余项）；
- 发布流水线扩展 v2.8.0 标签 + Phase45BenchmarkTest / Baseline 接入。

## 兼容性

- v1.0–v2.7 冻结协议不变，新增路径 additive；
- 跨云一阶段仅多数云合格时启用，否则回退 2PC；
- 多表 JOIN / 窗口下推与上层 SQL 结果一致；
- 全球统一时钟单调不回拨，恢复不回退。

## 质量摘要

- 新增测试 ≥530；全量回归 ≥9942 全绿；
- 基准：见 docs/benchmark/phase45-production-report.md；
- 门禁收敛表：docs/deployment/gate-convergence-v11.md。

## 已知限制

- 真实 Linux Runner / 跨机 / 跨地域门禁待 Phase 46 执行；
- 窗口函数仅 ROW_NUMBER/RANK；全球时钟为进程内多源模拟；
- 跨机基线为部署脚本 + 登记，真实执行待 Runner；
- 真实 S3/Spot 网络握手待 Runner。
