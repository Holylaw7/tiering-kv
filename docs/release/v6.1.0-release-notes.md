# Tiering-KV v6.1.0 Release Notes

- 发布日期：2026-11-26
- 类型：运维闭环与分布式全链路打通（分布式 Gateway 运维命令与 Participant 物理快照 + 控制台定时备份策略 + JWT 实时吊销）
- 容器镜像（GHCR，4 套全量发布）：
  - `ghcr.io/holylaw7/tiering-kv:v6.1.0`（数据面内核，含分布式 Gateway 全量运维命令与 Participant 原子快照）
  - `ghcr.io/holylaw7/tiering-kv-operator:v6.1.0`（Kubernetes Operator 控制器）
  - `ghcr.io/holylaw7/tiering-kv-console-server:v6.1.0`（控制面后端，Flyway V11 + 定时备份策略 + JWT 实时吊销）
  - `ghcr.io/holylaw7/tiering-kv-console-web:v6.1.0`（控制面前端，定时备份策略 UI + 登出/改密令牌吊销联动）

## 核心变更

### 1. 分布式 Gateway 全量运维命令与 Participant 原子快照（A1）
- **增量事务运维 RPC**：`RpcMessageType` 向后追加 `TXN_SCAN(36)` / `TXN_SCAN_RESPONSE(37)` / `TXN_CHECKPOINT(38)` / `TXN_CHECKPOINT_RESPONSE(39)`（既有 `1..35` 线协议编号零变动），打通 `TxnParticipantClient` → `RegionTxnClient` → `TxnParticipantRpcHandler` → `TransactionParticipant` 双向链路。
- **Participant 物理快照原子落盘与启动恢复**：`ParticipantRuntime` 实现魔数 `TKVS` v1 二进制快照持久化（`FileDescriptor.sync()` + 临时文件原子替换 `region-<id>-checkpoint.snap`），进程重启时自动将快照恢复回 `MvccStorageEngine`。
- **Gateway 跨 Region 运维闭环**：
  - `CoordinatorStorageEngine` 实现跨 Region 扇出聚合并按无符号字典序归并的 `iterator()`（支撑 `SCAN` / `KEYS`）、实时活跃键统计 `size()`（支撑 `DBSIZE` 与 `# Keyspace`）以及全 Region 强失败感知 `checkpointAll()`；
  - `GatewayRuntime` 接线 `SlowLog(10_000L, 128)` 与 `PhysicalSnapshotCoordinator(storage::checkpointAll)`（支撑 `SLOWLOG`、`BGSAVE`、`LASTSAVE` 与 `# Persistence`），并在 `INFO` 及 `INFO cluster` / `INFO transaction` / `INFO txn` 暴露真实多 Region 拓扑与事务指标；
  - `CoordinatorRuntime` 修复同主机多端口 Peer 路由键冲突；新增 `GatewayRuntimeOpsTest`（真 TCP 多 Region 端到端闭环 + 重启恢复测试）；`scripts/kind-operator-e2e.sh` Stage 5 升级为硬断言 `ping=+PONG`、`dbsize=:[1-9][0-9]*` 与 `bgsave=+Background saving started`。

### 2. 控制台定时备份策略与 JWT `token_version` 实时吊销（A2）
- **Flyway `V11__backup_schedules_and_token_revocation.sql`**：为 `sys_user` 新增 `token_version BIGINT NOT NULL DEFAULT 0`，并新增 `backup_schedule` 定时备份策略表。
- **JWT 跨副本即时吊销闭环**：
  - `JwtService` 在令牌中写入 `ver` 声明，`JwtAuthenticationFilter` 实时核验数据库活跃状态（`status == 1`）与 `token_version`，在多副本 HA 控制面下无需新外部中间件即可实现跨副本即时失效；
  - 新增 `POST /api/v1/auth/logout`，并在主动登出、自助改密、管理员重置密码、禁用账号与角色变更时自动递增 `token_version` 并记录审计日志；
  - 前端 `auth.logoutAndRevoke()` 与顶栏登出/改密联动，登出触发服务端吊销、改密自动清理本地会话并引导重新登录。
- **定时备份策略与多副本 HA 单活调度**：
  - 新增 `/api/v1/backups/schedules` 完整 CRUD 与 `POST /{id}/run-now`（`ADMIN`/`OPS` 可写，`VIEWER` 只读），兼容 5 段 Unix Cron 与 6 段 Spring Cron，支持 `LOGICAL`（扫描导出 + `BackupRetentionService.purgeInstance` 安全认领留存清理）与 `CHECKPOINT`（物理 `BGSAVE`）双模式；
  - 后台调度通过 `DbLeaseLockService`（`scheduler:backup-schedule`）单活选主，确保多副本部署下零重复触发；
  - `BackupsView.vue` 新增「定时备份策略」管理面板；OpenAPI 快照（`docs/api/openapi.json`）与前端 `schema.d.ts` 同步更新（0 漂移）。

### 3. 全栈端到端门禁扩展（A3）
- 新增 Playwright 端到端规范 `console-web/e2e/backup-schedules-and-revocation.spec.ts`，实测覆盖定时备份策略创建/立即执行/启停/删除以及 UI 登出与改密后旧 JWT 立即返回 `401`；
- `docker-compose-ha-smoke` 增设跨副本 JWT 实时吊销校验（通过 Nginx 经一副本登出，连续向双副本请求 `/api/v1/auth/me` 全部返回 `401` 且 MySQL `token_version >= 1`）。

## 升级说明

- **数据面与分布式集群**：新增 RPC 消息类型为向后追加，WAL / SSTable / Raft / 2PC 格式零破坏；直接滚动升级 `ghcr.io/holylaw7/tiering-kv:v6.1.0` 与 `ghcr.io/holylaw7/tiering-kv-operator:v6.1.0` 即可启用分布式 `SCAN` / `DBSIZE` / `SLOWLOG` / `BGSAVE` 与快照持久化恢复。
- **控制面与数据库**：启动 `tiering-kv-console-server:v6.1.0` 时 Flyway 自动执行 `V11__backup_schedules_and_token_revocation.sql`（向 `sys_user` 追加默认值为 `0` 的 `token_version` 并新建 `backup_schedule` 表），存量数据零迁移成本。
