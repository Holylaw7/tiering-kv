# Tiering-KV v3.4.0 Release Notes

## 定位

Enterprise-ready Distributed Database v3.4.0（RC）：Redis 协议兼容、
LSM 冷热分层、Multi-Raft 分布式事务、数据结构与 RESP3/PubSub。

## 本版本能力

- 类型化值编码（ADR-0276）
- Hash / List / Set / ZSet 命令族（ADR-0277~0280，共 46 命令）
- RESP3 协议演进（ADR-0281，Map/Set/Double/Push + HELLO 3）
- Pub/Sub（ADR-0282，本地 broker + 模式订阅 + 集群广播 SPI）

## 质量摘要

- 命令注册表 90 个；新增测试 ≥560；全量回归 ≥13700/13700 全绿
- 基准：docs/benchmark/phase52-production-report.md

## 兼容性

- v1.0–v3.3 冻结协议不变；v3.4 扩展 additive；
- RESP2 客户端零影响（RESP3 需 HELLO 3）。

## 已知限制

- 整值重写 O(size)；ZSet 全排序；
- RESP3 连接接线 / Pub/Sub 连接投递 / 集群广播待 Phase 53+；
- 高级数据结构命令（HSCAN/ZRANGEBYLEX 等）待后续。
