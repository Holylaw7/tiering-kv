# Tiering-KV v2.5.0 Release Notes

## 新能力

- 真实执行门禁收敛表 v8 + JVM 级门禁扩展（ADR-0206）；
- Leveled Compaction 执行：合并 + tombstone + TTL + 层级落盘
  （ADR-0207，TD-077 关闭方向）；
- 悲观事务：提前加锁 + 冲突 + 死锁超时（ADR-0208）；
- Async Commit + resolved-ts：单区一阶段 + 回退 2PC + 单调水位
  （ADR-0209）；
- Coprocessor SQL 下推：FILTER / PROJECT / AGGREGATE（ADR-0210）；
- 自治 PD 调度：护栏内执行 + 熔断（ADR-0211）；
- 全球拓扑自发现：心跳 → 地域/AZ 分组 + 故障剔除（ADR-0211）；
- v2.5.0 发布流水线（ADR-0212）。

## 兼容性

- v1.0–v2.4 冻结协议不变，新能力全部 additive；
- 不修改 Raft safety / MVCC consistency / 事务状态机。

## 测试

- Phase 42 新增 502 项（surefire 口径）；
- 全量回归 **8357/8357 全绿**（+6 容器门控跳过）。

## 已知限制

- 真实执行门禁（CI 容器/磁盘混沌/kind/release/跨机跨地域）待 Runner；
- async commit 为单区一阶段；
- Coprocessor 为单算子下推。
