# Tiering-KV v3.0.0 Release Notes

## 定位

Enterprise-ready Distributed Database v3.0.0 GA：Redis 协议兼容、LSM
冷热分层、Multi-Raft 分布式事务、真实 Runner 闭环归档与全球一致性 GA。

## 本版本能力

- 真实执行门禁收敛 v13 + 执行归档（ADR-0241）；
- 跨云一阶段全球统一仲裁（ADR-0242）：任意拓扑 + 回退 2PC；
- RL 动态下推（ADR-0243）：Q 学习在线决策，语义层一致；
- TSO 量子/卫星授时原型（ADR-0244）：校正 + 单调 + 防回拨；
- 监管级合规证书（ADR-0245）：时间戳证书 + 轮换 + 外部验证；
- TiKV 跨机回归告警（ADR-0246）：快照 + 趋势 + 阈值告警；
- 真实凭据网络验证 v5（ADR-0246）：可达性 + 认证 + 权限 + 配额
  （TD-076 剩余项）；
- 发布流水线扩展 v3.0.0 标签 + Phase47BenchmarkTest / Baseline 接入。

## 兼容性

- v1.0–v2.9 冻结协议不变，v3.0 扩展 additive；
- 跨云一阶段仅在分层仲裁通过时启用，否则回退 2PC；
- RL 只改决策层，语义层与上层 SQL 结果一致；
- 量子授时单调不回拨；监管证书轮换后旧证书可验证。

## 质量摘要

- 新增测试 ≥550；全量回归 ≥11053 全绿；
- 基准：见 docs/benchmark/phase47-production-report.md；
- 门禁收敛表：docs/deployment/gate-convergence-v13.md。

## 已知限制

- 真实 Linux Runner / 跨机 / 跨地域门禁待 Phase 48 执行；
- RL 为单智能体 Q 学习；量子/卫星授时为模拟原型；
- 监管证书为自签名，法规自动映射后续阶段；
- 真实 S3/Spot 网络握手待 Runner。
