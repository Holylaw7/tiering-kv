# Tiering-KV v3.2.0 GA Release Notes

## 定位

Enterprise-ready Distributed Database v3.2.0（GA）：Redis 协议兼容、
LSM 冷热分层、Multi-Raft 分布式事务、工程基座可信化与真实门禁终态
封板。

- 版本模型与制品对齐（ADR-0262，revision 注入 + 一致性校验）
- 结构化日志与敏感信息脱敏（ADR-0263，slf4j/logback + Redactor）
- 质量门禁（ADR-0264，JaCoCo + SpotBugs + 依赖审计）
- 真实执行门禁最终处置 v16（ADR-0265，唯一终态 + 封板）
- CI 执行与 GA 发布流水线（ADR-0266，checksums + 基准接入）
- JMH 基准工程化（ADR-0267，三条核心路径可复现）
- 产品完成度基线（ADR-0268，能力分层 + 技术债终态）
