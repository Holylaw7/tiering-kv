# 论文图表编号与交叉引用规范

适用范围：`docs/thesis/*.md`（论文正文）。`docs/design/system-design-and-verification.md`
作为工程文档保留原有连续编号（图 1–6），不受本规范影响。

## 1. 编号规则

一律采用**章节编号**，不使用全文连续编号：

| 类型 | 格式 | 示例 |
| --- | --- | --- |
| 图 | 图 `<章>-<序>`，题注在图下方 | 图 3-1、图 5-2 |
| 表 | 表 `<章>-<序>`，标题在表上方 | 表 3-2、表 4-1 |
| 公式 | 式（`<章>-<序>`），编号右对齐 | 式（3-1） |
| 代码清单 | 清单 `<章>-<序>`，标题在代码块上方 | 清单 3-1、清单 4-1 |

正文引用统一写"如图 3-1 所示""见表 4-2"，不写"见下图""见附表"。
