## 2. 使用规则

1. 首次出现时写"中文（英文/代码标识）"，此后统一用中文或代码标识，不混用；
2. 术语表中标注"禁止"的写法一律不得出现在正文；
3. 涉及能力边界的术语（ARC、Percolator、MVCC、快照读、线性一致读、合并式恢复）必须与限定语同时出现；
4. 测试相关术语严格区分"断言 / 测试方法数 / 测试执行次数 / 覆盖率口径"四类，不得互相替代。
