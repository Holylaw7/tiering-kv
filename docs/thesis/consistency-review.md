## 4. 术语统一

| 概念 | 统一用词 | 禁用/避免 |
| --- | --- | --- |
| 内存表 | MemTable | 内存表（首次出现可注释，之后统一 MemTable） |
| 冷层文件 | SSTable | 磁盘表、SST 文件 |
| 合并 | Compaction | 压缩（易与压缩算法混淆） |
| 落盘 | flush + fsync（明确区分） | "同步写盘"（含糊） |
| 时间戳 | startTS / commitTS / readTS | 事务号、版本号（版本号仅指写入序号） |
| 证据等级 | E1 / E2 / E3（第五章定义） | "已支持""已实现"（无等级时视为过度声明） |
| 测试规模 | 测试执行次数（15,014）/ 测试方法数（约 6,7xx）/ 断言条数（91、22） | "测试用例数"（口径不明） |
| 覆盖率 | 行 / 分支 / 指令覆盖率（分别标注） | "测试覆盖率 62%"（未说明口径） |
