# 前言

本文的研究对象是一个面向冷热数据分层的键值存储系统及其配套的运维控制台。系统以 Redis 协议为对外接口，以 LSM 结构为存储主链路，在单机内存受限的条件下，通过水位驱动的落盘、迁移与回读机制承载超出内存容量的数据，并对外暴露可核验的运行指标。

本文的工作范围包括四个部分：其一是存储引擎与冷热分层机制的实现；其二是独立控制平面与可观测性体系的实现；其三是在有限范围内讨论分布式复制与一致性机制；其四是建立一套可复现的工程验证方法，并对每项能力标注其证据边界。系统的分布式能力在单机多进程环境下验证，未覆盖真实跨机网络与掉电场景，相关结论的适用范围在各章末尾与第七章中明确说明。

论文的组织如下：第二章介绍相关技术与总体设计；第三章至第五章分别阐述存储引擎、控制与管理模块、分布式与一致性机制的设计与实现；第六章给出测试与实验结果并分析其边界；第七章总结全文并讨论后续工作。各章的设计描述与其验证结果相互对应，文中出现的每一个实验数字均可追溯到具体的测试或测量过程。
