## 2. 与当前稿的核心冲突

### 冲突一：参考文献格式（最重要）

学校规范的参考文献**不是** GB/T 7714，而是简化格式：

```text
[序号] 作者1，作者2，……作者n.文章名.期刊名（版本）,出版年.卷次（期次）.页次。
```

并且明确规定：**参考文献最后没有"页次"一项**（页次只出现在页下注的注释里）。

当前 `references.md` 为 GB/T 7714-2025：`作者. 题名[J]. 刊名, 年, 卷(期): 起-止页. DOI.`
→ 需转换为：`作者1，作者2.文章名.期刊名,出版年.卷次（期次）.`（去 [J]/[C]/[M]、去 DOI、去页码）。

> 注：此前确定的"GB/T 7714-2025"是在未拿到学校规范时的默认选择；按"学校模板优先"的原则，
> 正式提交版应以学校规范为准。GB/T 版本可作为附录或内部存档保留。

### 冲突二：缺少摘要、Abstract、关键词、致谢

学校模板要求：摘要（中/英）+ 关键词（中/英）+ 正文 + 参考文献 + 致谢，缺一不可。
当前七章只有正文与参考文献，**摘要与致谢尚未撰写**。

### 冲突三：标题层级与"前言"

模板目录示例为：摘要 → Abstract → 前言 → 1 一级标题 → … → 参考文献 → 致谢。
当前稿以"第一章 绪论"开篇，没有"前言"。两种处理方式：

- 方案 A：把"第一章 绪论"作为 `1` 一级标题，不写前言（多数理工科论文如此）；
- 方案 B：补一段"前言"（研究背景简述），再进入 `1 绪论`。

### 与建议顺序的差异（需你确认）

本次按**学校规范**排列为：封面 → 原创性声明 → **目录** → 中文摘要 → Abstract → 前言 → 第一章…第七章 → 参考文献 → 致谢。

规范第二部分明确"目录"在"正文（含摘要、关键词）"之前；若你希望改为"摘要 → Abstract → 前言 → 目录 → 正文"，重新生成即可，但可能与学校模板顺序不一致。

### 打开后需做的一次操作

目录与页码为 Word 域，已在生成时更新；若你编辑后页码变化，全选（Ctrl+A）后按 **F9** → 只更新页码即可。
