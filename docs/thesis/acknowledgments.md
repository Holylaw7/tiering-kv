# 致谢

本论文的完成离不开许多人的帮助。

首先感谢我的指导教师。从选题方向的确定、系统架构的取舍，到实验方案的设计与论文结构的调整，老师都给出了具体而耐心的指导。尤其在"哪些结论可以写、哪些还不能写"这一问题上，老师反复强调证据边界，这直接影响了本文第六章与第七章的写作方式。

感谢学院各位老师在课程与开题阶段给予的意见，使我在存储引擎与分布式系统方向上建立了必要的理论基础。

感谢同组同学在环境搭建、测试联调与论文校对中的帮助。系统验证阶段的大量重复执行与故障复现，离不开他们的配合。

感谢我的家人一直以来的理解与支持。

最后，感谢开源社区。本文的实现参考并受益于 LSM-Tree、Raft、Percolator 等公开研究成果，以及 Redis、Netty、Spring Boot 等开源项目；没有这些工作，本系统的完成是难以想象的。

由于本人水平有限，论文中难免存在不足与错误，恳请各位老师批评指正。
