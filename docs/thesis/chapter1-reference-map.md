基线：`a3623b1`（第二章完成）　用途：第一章《绪论》的引用骨架

## 1. 筛选原则（确认版）

在你提出的原则基础上，我建议补充四条可执行规则：

| # | 规则 | 理由 |
| --- | --- | --- |
| R1 | 核心文献 **14–16 篇**，全部来自正式期刊或顶级系统会议（OSDI/SOSP/ATC/FAST/SIGMOD/CIDR/VLDB/OPODIS/TACO/TKDE/EMSE 等） | 保证论证权威性，避免以硕士论文或行业文章充数 |
| R2 | 中文文献 **1–2 篇**，只用于"国内研究现状"，且必须是正式期刊综述 | 体现国内脉络，同时避免中英文同源重复 |
| R3 | 技术规范 **单列**（S1–S4），不计入文献计数，不参与"研究现状"论述 | 规范是事实标准，不是研究成果 |
| R4 | 每条引用必须绑定**一个具体论点**（映射表"引用论点"列），禁止"综述式堆砌" | 防止为凑数量而引用 |

附加约束：

- **同一研究的中英文版本只引一篇**。《云原生数据库综述》（软件学报 2024）与 *Cloud-Native Databases: A Survey*（TKDE 2024）主题高度相近，需先核实是否为同组作者的同源成果；若同源，只保留中文版，另一版在脚注说明"英文拓展版"。
- **页码/DOI 未逐条核实者标"待核"**，定稿前用 DOI 解析或出版社页面核对，不把估计值写进参考文献。
- **不做"首次提出/国内空白"式结论**。HotRAP（ATC 2025）等工作已表明 LSM 与分层存储结合是活跃方向，本项目定位只能是"面向 Redis 协议兼容 KV 引擎的工程整合与验证"。
