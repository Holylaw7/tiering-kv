# 控制台视觉规范（TD-093）

> 目标：像"运维工具"，不像"AI 生成的演示页"。
> 取向参考 Stripe / Linear / Vercel 一脉的 SaaS 控制台实践：**中性色主导、克制的强调色、
> 密排数据、1px 描边分层、无装饰性动效**。

## 1. 原则

| 原则 | 具体做法 |
| --- | --- |
| 安静优先 | 强调色只出现在"可交互/当前态"（主按钮、激活导航、焦点环），像素占比 <5% |
| 描边而非投影 | 卡片/面板用 1px 描边分层，投影只留给浮层（下拉、弹窗、Toast） |
| 数据密度 | 表格行高 36–40px、表头 10–11px 小字、数字右对齐且等宽（tabular-nums） |
| 动效克制 | 只在 hover/press 上做 ≤160ms 过渡；路由切换无入场动画 |
| 层级靠对比 | 表面 3 级（bg / surface / surface-2）+ 文本 3 级（text / text-2 / text-3） |

## 2. 令牌

定义在 `console-web/src/styles/tokens.css`，同时映射到 Element Plus 变量。

### 颜色

| 用途 | 变量 | 值 |
| --- | --- | --- |
| 页面底色 | `--bg` | `#0a0d11` |
| 侧栏/次级底 | `--bg-subtle` | `#0d1116` |
| 面板 | `--surface` | `#121820` |
| 悬停/输入 | `--surface-2` | `#172029` |
| 激活 | `--surface-3` | `#1d2731` |
| 描边 | `--line` / `--line-strong` | `#212a34` / `#2d3742` |
| 文本 | `--text` / `--text-2` / `--text-3` | `#e7ecf2` / `#9ba7b4` / `#6b7784` |
| 强调 | `--accent` | `#4c8dff`（钴蓝，仅交互态） |
| 语义 | success / warn / danger | `#3fb950` / `#d9a441` / `#f0544f` |

### 尺寸

- 间距：4 的倍数（4 / 8 / 12 / 16 / 20 / 24 / 32）
- 圆角：控制件 **6px**、面板 **8px**、浮层 **10px**（不使用胶囊按钮）
- 控件高度：按钮 30px（小号 26px）、输入框 30–32px、表格行 36–40px
- 字号：正文 12.5–13px、表格 12.5px、表头 11.5px 大写字距 0.03em、指标值 22px/600

### 字体

- 无衬线：Inter → system-ui → PingFang SC / Microsoft YaHei
- 等宽：JetBrains Mono → ui-monospace（用于键名、地址、ID、数值）

## 3. 组件约定

| 组件 | 约定 |
| --- | --- |
| 侧栏 | 232px；按「概览 / 数据 / 运维 / 系统」分组，组标题 10.5px 大写；激活项为 `surface-3` 底 + 强调色图标 |
| 顶栏 | 52px；左侧仅"实例"上下文切换，右侧在线状态 + 账户菜单；**不再重复页面标题** |
| 页面头 | 标题 16px/600 + 一行说明（≤72ch）+ 右侧操作按钮 |
| 指标卡 | 标签 11.5px 灰、数值 22px 等宽、说明 11.5px；无渐变、无彩色图标 |
| 表格 | 表头大写小字、行间 1px 细线、悬停 `surface-2`、空态用 `EmptyState` 组件 |
| 标签 | 4px 圆角、20px 高、语义色仅用于状态；动作/角色用中性灰 |
| 空态 | 44px 线性图标 + 一句陈述句标题 + 一句说明（+ 可选操作） |
| 图表 | 1.5px 细线、面积填充 ≤14%、虚线网格、图例默认隐藏（由标题 hint 说明） |

## 4. 反模式（本项目明确禁止）

- ❌ 装饰性渐变卡片、发光背景、彩色 blob
- ❌ emoji 当图标（`⚡` 等）、胶囊形标签/按钮
- ❌ 每个路由的淡入淡出动画
- ❌ 满屏彩色统计卡（每个指标一个颜色）
- ❌ 大写字母 + 大字距的"营销感"标题
