# 控制台视觉规范（Light-first · TD-094）

> 目标：让人第一眼认为这是一套**成熟的数据库运维产品**，而不是 AI 生成的深色 Dashboard。
> 方法参考 Linear / Vercel / Supabase / Stripe Dashboard：**排版与留白建立层级，颜色只承担语义**。

## 1. 原则

| 原则 | 落地方式 |
| --- | --- |
| 排版优先 | 层级由字号、字重、间距和 hairline 建立，不靠彩色卡片 |
| 颜色克制 | 品牌色仅用于可交互与当前状态；主按钮用墨色（#16181C），不用满屏蓝 |
| 面与线 | 页面 #F7F8FA、面板 #FFFFFF、分隔 #ECEEF1；卡片靠 1px 描边，不靠投影 |
| 数据密度 | 表格行 40px、表头 11px 大写、数字右对齐等宽 |
| 信息节奏 | 状态条 → 指标带 → 水位 → 图表 → 明细表，逐层展开 |
| 动效 | 只做 hover/focus 的 ≤160ms 过渡，无页面入场动画 |

## 2. 色彩

| 用途 | 变量 | 值 |
| --- | --- | --- |
| 页面背景 | `--bg` | `#F7F8FA` |
| 面板 | `--surface` | `#FFFFFF` |
| 次级面（侧栏 / 表头） | `--surface-2` | `#FAFBFC` |
| 填充 / 激活 | `--surface-3` | `#F1F3F5` |
| 边框 | `--line` | `#E5E7EB` |
| 分隔线 | `--line-soft` | `#ECEEF1` |
| 主文字 | `--text-1` | `#202124` |
| 次级文字 | `--text-2` | `#626B78` |
| 辅助文字 | `--text-3` | `#9299A3` |
| 品牌 / 交互 | `--accent` | `#3B5BDB`（仅链接、激活、焦点环） |
| 主按钮 | `--ink` | `#16181C` |
| 成功 / 警告 / 错误 | — | `#18794E` / `#B45309` / `#C62828` |
| 终端工作区 | `--term-*` | 底 `#0F1115`、面 `#16191F`、文字 `#D7DCE3` |

## 3. 排版

| 元素 | 规格 |
| --- | --- |
| 字体栈 | Inter → system-ui → PingFang SC / Microsoft YaHei |
| 等宽 | JetBrains Mono → SFMono → Consolas（键名、地址、数值、终端） |
| 页面标题 | 20px / 600 / letter-spacing -0.02em |
| 区块标题 | 13px / 600 |
| 正文 | 13px / 1.55 |
| 表格 | 12px，表头 11px 大写 0.04em |
| 指标数值 | 24px / 600 / tabular-nums |
| 登录主标题 | 34px / 600 / -0.03em（唯一的大字号场景） |

## 4. 布局

- 侧栏 236px（白底 + 右侧 hairline），分组：概览 / 数据 / 运维 / 系统，组标题 10.5px 大写。
- 顶栏 52px：页面标题 · 实例选择器 · 运行状态 · 在线实例数 · 账号菜单。
- 内容区 `max-width: 1360px` 居中，页头下方一条 hairline，正文 28/32px 内边距。
- 页面结构不强制卡片：状态用文本行、指标用分隔带、水位用进度条、明细才用表格面板。

## 5. 组件

| 组件 | 规范 |
| --- | --- |
| 指标带 | 6 列网格，单元格间 1px 竖线，标签 11px 灰、数值 24px、说明 11px |
| 状态点 | 6px 圆点，成功绿 / 失败红 / 未知灰，文字同色但低饱和 |
| 表格 | 表头浅灰底、行间 hairline、hover 浅灰、空态用 `EmptyState` |
| 标签 | 4px 圆角、21px 高，仅状态用色；角色、类型、动作一律中性 |
| 终端 | 深色工作区（`--term-*`）：标题栏 + 输出区 + 输入行；提示符蓝色，错误红框 |
| 图表 | 1.5px 细线、10% 面积填充、虚线网格、白底 tooltip、无图例（由标题 hint 说明） |
| 空态 | 44px 线性图标 + 陈述句标题 + 说明（+ 可选操作） |

## 6. 明确禁止

- ❌ 大面积蓝紫渐变、霓虹发光、玻璃拟态
- ❌ 背景科技网格 / 3D 插画 / emoji 当图标
- ❌ 每个模块都套独立彩色卡片
- ❌ 所有按钮都用高饱和蓝
- ❌ 装饰性折线图或假数据
