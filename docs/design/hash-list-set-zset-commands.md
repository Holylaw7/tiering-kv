# Hash / List / Set / ZSet Commands

## Hash（ADR-0277）

HSET/HGET/HDEL/HEXISTS/HLEN/HKEYS/HVALS/HGETALL/HMGET/HMSET/
HINCRBY/HSETNX。

## List（ADR-0278）

LPUSH/RPUSH/LPOP/RPOP/LLEN/LRANGE/LINDEX/LSET/LREM/LTRIM。

## Set（ADR-0279）

SADD/SREM/SISMEMBER/SCARD/SMEMBERS/SPOP/SRANDMEMBER +
SINTER/SUNION/SDIFF + STORE 变体。

## ZSet（ADR-0280）

ZADD/ZSCORE/ZRANGE/ZREVRANGE/ZREM/ZCARD/ZINCRBY/ZRANGEBYSCORE/
ZCOUNT/ZRANK/ZREVRANK。

## 共同语义

- 写路径 `AtomicStringOps.update`（段锁原子 + TTL 保留）；
- 非本类型键 WRONGTYPE；空 list/set/zset 自动删键；
- 插入序稳定；ZSet 排序 (score asc, member 字典序)。
