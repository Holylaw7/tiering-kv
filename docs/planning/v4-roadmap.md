# v4.0 Roadmap

## 方向

- 多模型：SQL/向量生产化、JSON/时序；
- 多集群：联邦一致性、跨地域多活深化；
- 云原生：Operator 完整化、多云部署、SaaS 深化；
- 性能：真实 Runner 基线、Jepsen 外部化分区注入。

## 流程

RFC（docs/planning/rfc-template.md）→ 评审 → ADR → 分支开发。
