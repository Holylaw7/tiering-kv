# G0-5C 统一性能资格验证：测试计划

- 状态：**计划已定，执行未完成**
- After 基线：`807b653`；Before 基线：`7bbf14c`（G0-5 改造前）

## 1. 资格判定

| 判定 | 含义 |
| --- | --- |
| PASS | 所有预定义指标达标，无回归 |
| PASS WITH REGRESSION | 核心指标改善，但存在已记录、可接受的回归 |
| FAIL | 出现正确性问题或不可接受的退化 |
| NOT QUALIFIED | 环境不满足，或证据不足以判定 |

## 2. 必测项

| 对象 | 场景 | 指标 |
| --- | --- | --- |
| F1 | 10 万冷键；INFO / DBSIZE | INFO p50/p95/p99；**启动扫描耗时单独记录**；后台重算耗时 |
| F3 | 持续 GET/SET | 写吞吐；GET/SET p50/p99；后台刷新单次耗时 |
| F2 | 持续写 Span 超过容量 | Span 写入延迟；INFO 延迟；淘汰延迟；RSS/堆曲线 |
| F4 | 多线程 record + 并发 snapshot | record 吞吐；snapshot 延迟；每百万次分配量 |
| 全局 | INFO 与 GET/SET 并发 | 两组 p50/p95/p99 |

## 3. 方法

1. `git worktree` 分离 Before（`7bbf14c`）与 After（`807b653`）；
2. 两版本复用**同一数据目录**，保证冷层数据一致；
3. 同机、同 JDK、默认 JVM 参数；预热后采样，每项 3 轮，保留逐轮原始数据；
4. 记录 GC、堆/RSS、后台线程运行情况。

## 4. 风险

| 风险 | 影响 |
| --- | --- |
| 开发机非隔离 | 采样受其他进程干扰 |
| 冷层构造依赖迁移 | 迁移未完成则 F1 场景不成立 |
| Windows 文件缓存 | 冷层读放大可能被掩盖 |
