# G0-5B-4 证据：LatencyStats 同步开销治理（F4）

- 关联：ADR-0373、G0-5A F4
- 代码基线：`6d033c8`

## 1. 改动

| 项 | 旧实现 | 新实现 |
| --- | --- | --- |
| `record()` | `synchronized (current)` + 两次记录 | 两次 `LongAdder` 自增，**无监视器** |
| 窗口轮转 | 在监视器内重置/合并 | 每 60 秒加锁一次，`getAndSet` 替换引用 |
| `snapshot()` | 两次 `synchronized` 合并 | 读取两个引用后合并到局部直方图，不锁共享对象 |
| 桶边界 | 17 个固定微秒上界 | **不变** |
| 分位数 | 桶上界估算 + 最大值封顶 | **不变** |

## 2. 语义（ADR-0373 已写明）

- 每个样本在累计与窗口各记一次，互不重复；
- 快照为**近似一致**：合并期间的新写入会计入相邻窗口之一；
- 轮转期间可能短暂出现"上一窗口为空"，`snapshot()` 仍返回当前窗口；
- 仍有一次每快照分配（17 个 LongAdder），未采用共享可复用数组——正确性优先于零分配。

## 3. 测试（4 例，全部与旧算法对照）

| 用例 | 结果 |
| --- | --- |
| 32 个边界值（含边界±1）的桶归类 | 与旧实现一致 |
| 空样本 | 全零 |
| 单样本 1.2 ms | p50 = max = 1 ms（最大值封顶生效） |
| 8 线程 × 25,000 次记录 + 200 次并发快照 | 样本数恰为 200,000，快照不阻塞 |

既有 `LatencyHistogramTest`、`MetricsRegistryTest` 全部通过。

## 4. 回归

**全量内核：15,147 例，0 失败，13 跳过。**

## 6. 残余风险

| 项 | 说明 |
| --- | --- |
| 近似快照 | 分位数在轮转边界可能有极小偏差，未量化 |
| 每快照分配 | 17 个 LongAdder/次，INFO 频率下可接受，未优化 |
| 未压测 | 8 线程单测不等于真实负载；需与 F1/F3/F2 一起做统一性能资格验证 |

## 7. 结论

**PASS WITH RESIDUAL RISKS**：`record()` 不再竞争单一监视器，分位数与桶边界与旧实现一致；
性能资格验证仍留待 G0-5 统一收口。
