# G0-5B-1 证据：冷层存活键计数快照化（F1）

- 关联：ADR-0370、G0-5A F1
- 代码基线：`7bbf14c`

## 1. 改动范围

| 文件 | 改动 |
| --- | --- |
| `ColdStorageEngine.java` | `liveCount()` 改为读 `volatile` 快照；新增 `refreshLiveCount()` 与后台守护线程 `cold-live-count-refresher`（1 s 周期、单线程、失败保留旧快照）；构造时同步算一次；`close()` 中断线程 |
| `ColdLiveCountTest.java`（新增） | 9 个用例，覆盖增删改、tombstone、TTL、flush、compaction、重启、并发、INFO 读快照语义 |
| `ColdStorageEngineEntryTest`、`TieringReadStorageEngineTest` | 两处断言前补 `refreshLiveCount()`（语义变更，见 §4） |

INFO 调用链未改：`ServerInfoProvider` 仍读 `storageMetrics`，`total_keys` 经 `size()` 到 `liveCount()`，
但后者已是纯字段读取。

## 2. 语义（与 ADR-0370 一致）

| 场景 | 行为 | 测试 |
| --- | --- | --- |
| 新增键 | 下次刷新 +1 | `新增键后快照增加` |
| 覆盖已有键 | 计数不变 | `覆盖已有键计数不变` |
| 删除有效键 | 下次刷新 -1 | `删除有效键计数减少且重复删除不重复扣减` |
| 重复删除 | 不重复扣减 | 同上 |
| tombstone 与旧版本共存 | 只计最新存活状态 | `tombstone与新版本共存时计数正确` |
| TTL 过期 | 刷新后不计入 | `TTL过期后计数不包含该键` |
| Flush / compaction | 逻辑键数不变 | `Flush前后计数一致` |
| 重启 | 构造时重算，结果与磁盘一致 | `重启后计数恢复` |
| INFO 读取 | 返回快照，不触发扫描 | `INFO读取不触发扫描而是返回快照`（写入后未刷新时仍返回旧值） |
| 并发写删 | 刷新后与预期一致 | `并发写入与删除后刷新计数一致`（4 线程 × 250 写 + 50 删） |

## 3. 回归

| 范围 | 结果 |
| --- | --- |
| 新增用例 | 9 / 9 通过 |
| 受影响用例 | `ColdStorageEngineEntryTest` 5/5、`TieringReadStorageEngineTest` 7/7 |
| **全量内核回归** | **15,126 例，0 失败，13 跳过**（跳过项仍为环境门控：K8s/块设备/容器网络） |

> 与论文基线 15,014 的差异：基线之后仓库新增了测试（含本次 9 例），未逐条比对差异来源。

## 4. 对既有测试的调整（不是弱化断言）

两处断言在写入后立即读 `liveCount()`，此前依赖"读取时惰性重算"；现在语义改为"后台快照"，
因此在断言前补一次 `refreshLiveCount()`。**断言数值未改**，仍为 1/2/5。

## 5. 性能验证：**未执行**

本轮**没有**做 10 万冷键的 INFO 延迟对照，原因：

1. 需要在同机、同 JVM 参数、同数据规模下分别跑"修改前/修改后"；
2. 修改前的行为是"写入后首次 INFO 触发全量扫描"，其耗时与冷层规模线性相关，构造可比基线成本较高；
3. 本会话剩余时间不足以完成可信的三轮采样。

**因此不声称性能提升，只声称"INFO 路径不再触发扫描"（由代码结构与单测保证）。**
历史观测可作参照但不能直接比较：`DBSIZE` 冷层扫描 17.1 ms（6 表 / 597 MB，第 6 章）。

## 6. 残余风险与未覆盖

| 项 | 说明 |
| --- | --- |
| 启动扫描 | 构造时同步重算一次；冷层越大启动首帧越慢。未做持久化计数（见 ADR-0370 决策） |
| 陈旧窗口 | 写入后最长约 1 秒（刷新周期 + 重算耗时）内 INFO/DBSIZE 可能偏小 |
| 后台线程开销 | 每秒一次脏检查；脏时全量重算，与写入争用冷层锁；未做重算耗时的长期观测 |
| 崩溃恢复 | 计数不持久化，重启即重算，不存在"计数与数据不一致"的持久化风险 |
| 大规模冷层 | 未在 10 万键以上验证刷新耗时 |

## 7. 结论

**PASS WITH RESIDUAL RISKS**：INFO 路径的全量扫描已消除（F1 目标达成），
计数语义经 9 个用例与全量回归验证；启动扫描与 1 秒陈旧窗口作为明确语义保留，未伪装成零成本。
