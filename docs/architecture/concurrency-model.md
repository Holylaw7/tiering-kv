# 并发模型（Concurrency Model）

状态：Accepted（ADR-0003）

## 1. 分层并发策略

| 层 | 策略 |
| --- | --- |
| 网络 | Netty 事件循环（boss/worker），IO 线程无阻塞 |
| 命令执行 | 有界工作线程池 + 按 key 哈希分片，单 key 有序 |
| 内存表 | 分段锁（64 分片起步），无全局锁 |
| 读热路径 | 不可变快照 / volatile 发布，接近无锁 |
| 热度管理 | 后台采样线程（窗口 100ms），不阻塞请求 |
| 迁移 | scheduler 有界队列 + 专用线程池，可取消可重试 |

## 2. 规则

- 禁止全局锁；跨分片操作走分阶段锁或协调协议；
- 锁顺序全局约定，避免死锁；
- 队列饱和必须表现为背压而非无限堆积。

## 3. 演进

- Phase 7：分段细化、无锁读路径、热点 key 缓解；
